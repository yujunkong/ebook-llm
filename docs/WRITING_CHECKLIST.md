## 필수

- [ ] `# N강. 제목` (또는 호환 `# 제N강. 제목`)
- [ ] `## 이번 강에서 배우는 내용`
- [ ] `## 왜 중요한가?` (또는 동등 절)
- [ ] Heading 최대 4단
- [ ] 인라인 `$...$` · 블록 `$$...$$`
- [ ] 코드 블록 언어 표시
- [ ] NumPy · PyTorch 실습 (가능하면 2개+)
- [ ] `## LLM에서는 어디에 사용될까?`
- [ ] 핵심 요약 · 용어 사전 · 연습문제
- [ ] 강의 이동(LECTURE_NAV)
- [ ] ChatGPT 대화체 없음
- [ ] Sigil 전용 HTML/인라인 CSS 없음

## 권장 본문 흐름

1. 배우는 내용 · 왜 중요한가
2. 개념 → 수식 → 작은 숫자 → 그림
3. NumPy / PyTorch 실습
4. LLM 연결
5. 핵심 요약 · 용어 · 연습문제(기초·계산·코드·응용)
