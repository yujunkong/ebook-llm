# 강의 작성 체크리스트

각 강의를 쓰기 전·후에 확인한다.

## 필수

- [ ] 제목: `제XX강. 제목`
- [ ] Heading: 권 H1 / 강의 H2 / 절 H3 / 세부 H4
- [ ] 처음 등장 용어: 영어 · 한국어 · 쉬운 정의 · 왜 필요한지 · 예제
- [ ] 직관 → 수학 → 숫자 → 코드 → LLM 연결 (개념에 맞게 조절)
- [ ] ChatGPT 대화체 없음
- [ ] 이전 강의 / 다음 강의 연결
- [ ] 복습 문제 + 정답·해설
- [ ] 핵심 용어 정리

## 권장 구조

1. 이번 강의에서 배울 것
2. 왜 이것을 배우는가
3. 먼저 알아야 할 개념
4. 핵심 개념 설명
5. 직관적으로 이해하기
6. 수학적으로 이해하기
7. 작은 숫자로 직접 계산하기
8. 코드로 구현하기
9. PyTorch로 구현하기
10. 실제 LLM에서는 어떻게 사용하는가
11. 실습
12. 자주 하는 실수
13. 핵심 정리
14. 핵심 용어
15. 복습 문제
16. 다음 강의와 연결

불필요한 항목은 생략할 수 있다.

## EPUB 주의

- 수식은 일관된 LaTeX/MathML 변환 가능 형식 사용
- 코드 블록에 언어 표시
- 복잡한 병합 표 지양
- 이미지에는 `그림 XX-N. 설명` 형식의 캡션
