# 강의 작성 체크리스트

자세한 규칙은 [MARKDOWN_STYLE_GUIDE.md](MARKDOWN_STYLE_GUIDE.md)를 따른다.

## 필수

- [ ] `# 제XX강. 제목` (H1)
- [ ] `> **학습 목표**` 블록
- [ ] Heading 최대 4단 (`#`~`####`)
- [ ] 인라인 수식 `$...$`, 블록 수식 `$$...$$` (빈 줄 포함)
- [ ] `\\(...\\)` 미사용
- [ ] 코드 블록에 언어 표시
- [ ] 핵심 정리 · 연습 문제
- [ ] 강의 이동(LECTURE_NAV) 링크
- [ ] ChatGPT 대화체 없음

## 권장 본문 흐름

1. 개념 소개
2. 동작 원리 / 수학·숫자 예제
3. 코드·실습
4. LLM 연결
5. 핵심 정리 · 용어 · 연습 문제
