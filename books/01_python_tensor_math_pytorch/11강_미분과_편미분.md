# 제11강. 미분과 편미분

> **학습 목표**
> - Derivative(미분, 도함수)의 직관과 정의
> - 기본 미분 공식 몇 가지를 손으로 쓰기
> - Partial Derivative(편미분)가 필요한 이유
> - 다변수 함수에서 “한 변수만 움직일 때”의 기울기
> - 이것이 왜 LLM의 Parameter 학습으로 이어지는지 (예고)

---
## 1. 왜 이것을 배우는가

학습(training)이란 Roughly:

```text
Loss가 작아지도록 Parameter를 조금 움직인다
```

“어느 방향으로, 얼마나”를 알려면 **Loss가 Parameter에 대해 얼마나 민감한지**를 알아야 한다.  
그 민감도가 미분이다.

미분을 “공식 암기”로만 지나면, `loss.backward()`가 무엇을 계산하는지 영원히 검게 남는다.  
이번 강의는 그 상자를 연다.

## 2. 먼저 알아야 할 개념

- 함수 $f(x)$ : 입력 $x$를 받아 출력 $f(x)$를 준다
- 일차함수, 이차함수의 그래프 감각
- Scalar / Vector (9강)
- 극한의 엄밀한 $\varepsilon$-$\delta$ 정의는 필요하지 않다. “한없이 가깝게” 직관이면 충분하다

## 3. 핵심 개념 설명

### 3.1 Derivative (미분 / 도함수)

**Derivative(미분계수/도함수)**는 함수가 어떤 점에서 **순간적으로 얼마나 가파른지**를 나타내는 값(또는 그 값을 주는 함수)이다.

한 점 $x$에서

$$

f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}

$$

기호 설명:

- $f$: 미분할 함수
- $x$: 관심을 두는 입력 지점
- $h$: 아주 작은 입력 변화량
- $f(x+h)-f(x)$: 출력의 변화량
- 분수: “출력 변화 / 입력 변화” = 평균 변화율
- $h\to 0$: 그 간격을 한없이 줄여 **순간** 변화율로 만든다
- $f'(x)$: $x$에서의 미분계수. $\dfrac{df}{dx}$와 같은 뜻

왜 필요한가?

- $f'(x)>0$이면 그 근처에서 $x$를 키울 때 $f$도 커진다.
- $f'(x)<0$이면 $x$를 키울 때 $f$는 작아진다.
- $|f'(x)|$가 클수록 민감하다.

학습에서는 “Loss를 줄이려면 Parameter를 어느쪽으로 밀까?”에 바로 쓰인다.

### 3.2 표기법

같은 뜻을 여러 방식으로 쓴다.

$$

f'(x),\quad \frac{df}{dx},\quad \frac{d}{dx}f(x)

$$

- $f'$: 프라임 표기
- $\frac{df}{dx}$: “$x$에 대한 $f$의 변화율”

다변수로 가면 편미분 기호 $\partial$를 쓴다 (4.5절).

### 3.3 기본 공식 (암기보다 사용)

자주 쓰는 것만 정리한다. $c$는 상수.

| 함수 | 도함수 |
|---|---|
| $f(x)=c$ | $f'(x)=0$ |
| $f(x)=x$ | $f'(x)=1$ |
| $f(x)=cx$ | $f'(x)=c$ |
| $f(x)=x^n$ | $f'(x)=n x^{n-1}$ |
| $f(x)=e^x$ | $f'(x)=e^x$ |
| $f(x)=\ln x$ | $f'(x)=1/x$ ($x>0$) |

선형성:

$$

\frac{d}{dx}\big(af(x)+bg(x)\big) = a f'(x) + b g'(x)

$$

곱의 미분, 합성함수 미분(Chain Rule)은 14강에서 본격적으로 다룬다.  
다만 미리 한 줄만:

$$

\frac{d}{dx}f(g(x)) = f'(g(x))\cdot g'(x)

$$

## 4. 직관적으로 이해하기

산을 걷고 있다고 상상하자.

- 높이 = 함수 값 $f(x)$
- 발밑의 기울기 = $f'(x)$

$x$를 “위치”, $f$를 “높이”로 보면:

```text
기울기가 +2  → 한 걸음 오른쪽으로 가면 높이가 약 2 증가
기울기가 -3  → 한 걸음 오른쪽으로 가면 높이가 약 3 감소
기울기가  0  → 평지 (국소 최대/최소/안장 후보)
```

근사식 (선형 근사):

$$

f(x+h) \approx f(x) + f'(x)\, h

$$

아주 작은 $h$에 대해, 곡선 대신 **접선**으로 근사한다.  
딥러닝의 파라미터 업데이트도 이 1차 근사 감각 위에 있다.

## 5. 작은 숫자로 직접 계산하기

### 5.1 정의로 미분하기 — $f(x)=x^2$

$x=3$에서:

$$

f'(3) = \lim_{h\to 0}\frac{(3+h)^2 - 3^2}{h}
= \lim_{h\to 0}\frac{9 + 6h + h^2 - 9}{h}
= \lim_{h\to 0}(6 + h) = 6

$$

공식으로도: $f'(x)=2x$이므로 $f'(3)=6$. 일치한다.

수치로 $h=0.001$:

$$

\frac{(3.001)^2 - 9}{0.001} = \frac{9.006001 - 9}{0.001} = 6.001

$$

이미 6에 가깝다.

### 5.2 $f(x)=3x+1$

$$

f'(x)=3

$$

어디서든 기울기가 3인 직선이다.  
$x$를 1 키우면 $f$는 정확히 3 커진다.

### 5.3 $f(x)=(2x-1)^2$ — 나중에 Chain Rule로 깔끔해짐

지금은 전개해서:

$$

f(x)=4x^2 - 4x + 1, \quad f'(x)=8x-4

$$

$x=1$이면 $f'(1)=4$.

의미: $x=1$ 근처에서 $x$를 조금 키우면 $f$는 약 4배속으로 커진다.

### 5.4 Loss처럼 보이는 1변수 예

예측 $\hat{y}=wx$, 정답 $y$, 제곱오차

$$

L(w) = (wx - y)^2

$$

$x=2$, $y=4$로 고정하면

$$

L(w)=(2w-4)^2 = 4(w-2)^2

$$

$$

L'(w)=8(w-2)

$$

- $w=2$이면 $L'=0$ (이미 정답)
- $w=3$이면 $L'=8>0$ → $w$를 키우면 Loss가 커짐 → **줄이려면 $w$를 줄여야** 함
- $w=1$이면 $L'=-8<0$ → $w$를 키우면 Loss가 작아짐

이 한 줄이 12강 Gradient Descent의 씨앗이다.

## 6. Partial Derivative (편미분)

### 6.1 정의

입력이 여러 개일 때, **한 변수만** 움직이고 나머지는 상수로 둔 채 미분하는 것이 **Partial Derivative(편미분)**이다.

$$

f(x, y)

$$

에 대해

$$

\frac{\partial f}{\partial x}
=
\lim_{h\to 0}
\frac{f(x+h,\ y) - f(x,y)}{h}

$$

$$

\frac{\partial f}{\partial y}
=
\lim_{h\to 0}
\frac{f(x,\ y+h) - f(x,y)}{h}

$$

기호:

- $\partial$: 편미분 기호 (라운드 디, “partial”)
- $\frac{\partial f}{\partial x}$: $y$를 고정한 채 $x$ 방향 기울기
- $\frac{\partial f}{\partial y}$: $x$를 고정한 채 $y$ 방향 기울기

왜 필요한가?

- LLM Parameter는 하나가 아니다. 수백만~수천억 개다.
- Loss는 그 모든 파라미터의 함수다.
- “$W_{17}$만 조금 바꾸면 Loss가 어떻게 되나?”가 곧 $\partial L / \partial W_{17}$이다.

### 6.2 기호 $d$와 $\partial$의 감각

- $d$: 실질적으로 한 변수 함수, 또는 전미분 맥락
- $\partial$: 여러 변수 중 일부만 볼 때

초보 단계에서는 “입력이 여러 개면 $\partial$”라고 기억해도 실무에 충분하다.

## 7. 다변수 작은 숫자 예

### 7.1 $f(x,y)=x^2 + 3xy + y^2$

$y$를 상수로 보고 $x$로 미분:

$$

\frac{\partial f}{\partial x} = 2x + 3y

$$

$x$를 상수로 보고 $y$로 미분:

$$

\frac{\partial f}{\partial y} = 3x + 2y

$$

점 $(x,y)=(1,2)$에서:

$$

\frac{\partial f}{\partial x}=2\cdot1+3\cdot2=8,
\quad
\frac{\partial f}{\partial y}=3\cdot1+2\cdot2=7

$$

의미:

- $x$만 $+0.01$ → $f$는 약 $8\times 0.01=0.08$ 증가
- $y$만 $+0.01$ → $f$는 약 $0.07$ 증가

### 7.2 손확인 (수치)

$$

f(1,2)=1 + 6 + 4=11

$$

$$

f(1.01, 2)=1.01^2 + 3\cdot1.01\cdot2 + 4 = 1.0201 + 6.06 + 4 = 11.0801

$$

증가량 $0.0801$ ≈ $0.08$. 편미분과 일치.

### 7.3 간단한 2파라미터 Loss

입력 $x=1$, 정답 $y=5$,

$$

\hat{y} = w_1 x + w_2 = w_1 + w_2

$$

$$

L(w_1, w_2) = (\hat{y}-y)^2 = (w_1 + w_2 - 5)^2

$$

편미분:

$$

\frac{\partial L}{\partial w_1} = 2(w_1 + w_2 - 5)\cdot 1

$$

$$

\frac{\partial L}{\partial w_2} = 2(w_1 + w_2 - 5)\cdot 1

$$

$w_1=2$, $w_2=1$이면 $\hat{y}=3$, $L=(3-5)^2=4$,

$$

\frac{\partial L}{\partial w_1}=\frac{\partial L}{\partial w_2}=2(3-5)=-4

$$

둘 다 음수 → 각 파라미터를 **키우면** Loss가 줄어드는 방향이다 12강에서 이 숫자들로 실제 업데이트를 한다.

## 8. 코드로 구현하기 — 수치 미분

해석 미분(공식)과 수치 미분(작은 h)을 비교한다.

```python
# lecture11_numerical_derivative.py
import numpy as np

def f(x: float) -> float:
    return x ** 2

def numerical_derivative(func, x: float, h: float = 1e-5) -> float:
    """중앙차분: (f(x+h)-f(x-h)) / (2h) — 단순 전방차분보다 오차가 작은 편"""
    return (func(x + h) - func(x - h)) / (2 * h)

x0 = 3.0
approx = numerical_derivative(f, x0)
exact = 2 * x0
print("approx:", approx, "exact:", exact)

def g(x: float, y: float) -> float:
    return x**2 + 3 * x * y + y**2

def partial_x(func, x, y, h=1e-5):
    return (func(x + h, y) - func(x - h, y)) / (2 * h)

def partial_y(func, x, y, h=1e-5):
    return (func(x, y + h) - func(x, y - h)) / (2 * h)

print("df/dx ~", partial_x(g, 1.0, 2.0), "exact", 2*1 + 3*2)
print("df/dy ~", partial_y(g, 1.0, 2.0), "exact", 3*1 + 2*2)
```

수치 미분은 검증용으로 강력하다. 이후 Autograd 결과를 의심할 때 “작은 네트워크 + 수치 미분”으로 대조한다.

## 9. PyTorch Autograd 맛보기 (예고)

원리는 11~14강에서 쌓고, 자세한 Autograd는 이후 PyTorch 강의에서 다룬다.  
다만 “같은 값”을 미리 본다.

```python
# lecture11_torch_grad_preview.py
import torch

w = torch.tensor(3.0, requires_grad=True)
L = (2 * w - 4) ** 2   # 6.4절과 동일 구조
L.backward()
print(w.grad)  # tensor(8.)  ← L'(3)=8
```

`backward()`가 내부적으로 미분(정확히는 Chain Rule로 편미분을 전파)을 수행한다.

## 10. 실제 LLM에서는 어떻게 사용하는가

LLM의 Loss $L$는 모든 Parameter $\theta$의 함수다.

$$

L = L(\theta), \quad \theta = \{W^{(1)}, b^{(1)}, W^{(2)}, \ldots\}

$$

학습에 필요한 것은

$$

\frac{\partial L}{\partial \theta_i}
\quad \text{for every parameter } \theta_i

$$

이다.

- 한 파라미터씩 수치 미분하면 너무 느리다 (파라미터가 수십억이면 불가능에 가깝다).
- 그래서 **해석적 미분 + Chain Rule + 역전파**로 한 번의 후진 계산에 모든 편미분을 구한다.

이번 강의에서 할 일은:

> “편미분이란 무엇인가”를 숫자로 이해한 뒤,  
> 다음 강의에서 그 편미분들을 **벡터로 묶어 Gradient**라 부르는 것

까지 자연스럽게 연결하는 것이다.

또한 Embedding·Attention 안의 곱셈·덧셈·Softmax·LayerNorm도 모두 미분이 가능해야(또는 거의 어디서나) 학습이 된다. “미분 가능성”이 딥러닝 연산 선택의 숨은 조건이다.

## 12. 자주 하는 실수

1. **평균 변화율과 순간 변화율을 혼동한다**  
   $h$가 작지 않으면 접선이 아니라 할선이다.

2. **편미분에서 다른 변수를 같이 動か 않는다**  
   $\partial f/\partial x$를 볼 때 $y$는 고정이다.

3. **$f'$의 부호를 업데이트 방향과 반대로 읽는다**  
   Loss를 줄이려면, 보통 파라미터가 미분의 **반대** 방향으로 움직인다 (12강).

4. **합성함수인데 그냥 $x$만 미분한다**  
   $ (2x-1)^2 $처럼 겉과 속이 있으면 Chain Rule이 필요하다. 지금은 전개로 우회했고, 14강에서 정식으로 다룬다.

5. **수치 미분의 $h$를 너무 크게/너무 작게 잡는다**  
   너무 크면 근사 오차, 너무 작으면 부동소수점 오차. $10^{-5}$ 근처가 실습에 무난하다.

## 13. 핵심 정리

- 미분은 “입력 변화에 대한 출력의 순간 민감도”다.
- $f'(x)>0$이면 $x$ 증가 시 $f$ 증가 경향, $<0$이면 감소 경향.
- 편미분은 다변수 함수에서 한 변수만의 민감도이다.
- LLM 학습은 결국 $\partial L/\partial \theta_i$를 구해 파라미터를 움직이는 일이다.
- 수치 미분은 검증 도구, Autograd/역전파는 확장 가능한 계산 도구다.

## 14. 핵심 용어

| 용어 | 의미 |
|---|---|
| Derivative (미분/도함수) | 순간 변화율 $f'(x)$ |
| Difference Quotient | $(f(x+h)-f(x))/h$ 평균 변화율 |
| Partial Derivative (편미분) | 다른 변수를 고정한 채 한 변수로 미분 |
| Gradient (예고) | 모든 편미분을 모은 벡터 (12강) |
| Linear Approximation | $f(x+h)\approx f(x)+f'(x)h$ |
| Numerical Differentiation | 작은 $h$로 미분을 근사 |
| Autograd | 자동 미분 시스템 |

Loss가 수많은 파라미터의 함수이기 때문이다. 한 파라미터의 영향을 말할 때는 나머지를 고정한 편미분이 자연스럽다.

### 문제 5

$L'(3)=8>0$이므로 $w$를 키우면 Loss가 커진다. 줄이려면 $w$를 감소시켜야 한다. (예: $3\to 2$ 쪽으로)

## 16. 다음 강의와 연결

이번 강의에서 “기울기라는 숫자”를 얻었다.

다음 **제12강. Gradient와 Gradient Descent**에서는 편미분들을 묶어 **Gradient 벡터**로 만들고,  

$$

\theta \leftarrow \theta - \eta \nabla L

$$

로 파라미터를 갱신하는 법을 작은 예제로 끝까지 계산한다.

> 민감도를 알았으면, 이제 산을 내려가자.
