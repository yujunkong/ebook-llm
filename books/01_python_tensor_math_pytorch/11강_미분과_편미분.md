# 11강. 미분과 편미분

## 이번 강에서 배우는 내용

- **Derivative(미분)**의 정의 · 기하 의미 · 기본 공식
- **Partial Derivative(편미분)** — 한 변수만 움직일 때의 기울기
- Loss $L(w)$에서 미분 부호가 업데이트 방향을 알려 주는 이유
- 수치 미분과 Autograd의 역할 차이
- LLM Parameter 학습이 왜 편미분의 묶음(Gradient)으로 이어지는지

## 왜 중요한가?

학습(training)이란 대략 다음입니다.

```text
Loss가 작아지도록 Parameter를 조금 움직인다
```

“어느 방향으로, 얼마나”를 알려면 **Loss가 Parameter에 얼마나 민감한지**를 알아야 합니다.

그 민감도가 미분입니다.

`loss.backward()`가 무엇을 계산하는지 이해하려면, 미분·편미분의 숫자 감각이 필요합니다.

> **핵심**
>
> 미분 = 순간 변화율. 편미분 = 여러 파라미터 중 **하나만** 볼 때의 변화율.

## 선수 개념

- 함수 $f(x)$
- Scalar / Vector (9강)
- 내적 · 행렬곱 · $y=xW+b$ (10강)

극한의 $\varepsilon$-$\delta$ 정의는 필요하지 않습니다. “한없이 가깝게”면 충분합니다.

## 미분 (Derivative)

한 점 $x$에서

$$
f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
$$

위 식을 **미분의 정의식**이라고 부릅니다.

- $h$: 아주 작은 입력 변화
- 분자: 출력 변화
- 분수: 평균 변화율 → $h\to0$이면 **순간** 변화율
- $f'(x)=\dfrac{df}{dx}$와 같은 뜻

**그림 11-1. 미분은 접선의 기울기**

![그림 11-1](images/fig11-01.svg)

- $f'(x)>0$: $x$를 키우면 $f$도 커지는 경향
- $f'(x)<0$: $x$를 키우면 $f$는 작아지는 경향
- $|f'(x)|$가 클수록 민감

### 정의로 끝까지 — $f(x)=x^2$ at $x=3$

$$
f'(3)
=\lim_{h\to0}\frac{(3+h)^2-9}{h}
=\lim_{h\to0}\frac{9+6h+h^2-9}{h}
=\lim_{h\to0}(6+h)
=6
$$

공식 $f'(x)=2x$로도 $f'(3)=6$. 일치합니다.

$h=0.001$이면 전방차분 $6.001$ — 이미 매우 가깝습니다.

### 표기와 기본 공식

$$
f'(x),\quad \frac{df}{dx},\quad \frac{d}{dx}f(x)
$$

| 함수 | 도함수 |
|---|---|
| $c$ | $0$ |
| $x$ | $1$ |
| $cx$ | $c$ |
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ ($x>0$) | $1/x$ |

선형성:

$$
\frac{d}{dx}\big(af+bg\big)=a f'+b g'
$$

> 📘 **심화**
>
> 합성함수: $\dfrac{d}{dx}f(g(x))=f'(g(x))g'(x)$. 본격적으로는 **14강 Chain Rule**.

## 직관 — 산의 기울기와 근사

높이를 $f(x)$, 발밑 기울기를 $f'(x)$로 보면:

```text
기울기 +2 → 오른쪽 한 걸음에 높이 약 +2
기울기 -3 → 오른쪽 한 걸음에 높이 약 -3
기울기  0 → 평지 (국소 최대/최소 후보)
```

선형 근사:

$$
f(x+h)\approx f(x)+f'(x)\,h
$$

파라미터 업데이트도 이 **1차 근사** 감각 위에 있습니다.

## Loss와 미분 부호

예측 $\hat y=wx$, 정답 $y$, 제곱오차

$$
L(w)=(wx-y)^2
$$

$x=2$, $y=4$이면 $L(w)=(2w-4)^2=4(w-2)^2$, $L'(w)=8(w-2)$.

| $w$ | $L'(w)$ | Loss를 줄이려면 |
|---:|---:|---|
| 2 | 0 | 이미 정지점 |
| 3 | +8 | $w$를 **줄임** |
| 1 | −8 | $w$를 **키움** |

**그림 11-3. Loss 곡선과 미분 부호**

![그림 11-3](images/fig11-03.svg)

> ⚠️ **주의**
>
> Loss↓ 방향은 보통 미분의 **반대**입니다. $w\leftarrow w-\eta L'(w)$ (12강).

또 다른 예: $f(x)=3x+1$ → $f'=3$ (어디서든 기울기 3).

$f(x)=(2x-1)^2$을 전개하면 $4x^2-4x+1$, $f'=8x-4$. $x=1$이면 $4$.

## 편미분 (Partial Derivative)

입력이 여러 개일 때 **한 변수만** 움직이고 나머지는 상수로 둔 채 미분합니다.

$$
\frac{\partial f}{\partial x}
=\lim_{h\to0}\frac{f(x+h,y)-f(x,y)}{h}
$$

$$
\frac{\partial f}{\partial y}
=\lim_{h\to0}\frac{f(x,y+h)-f(x,y)}{h}
$$

**그림 11-2. 편미분은 한 축만의 기울기**

![그림 11-2](images/fig11-02.svg)

LLM Parameter는 수백만~수천억 개입니다. “$W_{ij}$만 흔들면 Loss가 어떻게 되나?”가 곧 $\partial L/\partial W_{ij}$입니다.

> 💡 **팁**
>
> 초보 단계에서는 “입력이 여러 개면 $\partial$”로 기억해도 실무에 충분합니다.

### 예 — $f(x,y)=x^2+3xy+y^2$

$$
\frac{\partial f}{\partial x}=2x+3y,\quad
\frac{\partial f}{\partial y}=3x+2y
$$

$(1,2)$에서 $8$, $7$.

수치: $f(1,2)=11$, $f(1.01,2)=11.0801$ → 증가 $0.0801\approx0.08$.

### 2파라미터 Loss

$\hat y=w_1+w_2$, $y=5$,

$$
L(w_1,w_2)=(w_1+w_2-5)^2
$$

$$
\frac{\partial L}{\partial w_1}
=\frac{\partial L}{\partial w_2}
=2(w_1+w_2-5)
$$

$w_1=2$, $w_2=1$이면 편미분이 각 $-4$입니다. 12강에서 이를 묶어 **Gradient 벡터**라 부릅니다.

## 수치 미분과 Autograd

전방차분:

$$
f'(x)\approx\frac{f(x+h)-f(x)}{h}
$$

| $h$ | 문제 |
|---|---|
| 너무 큼 | 할선 오차 |
| 너무 작음 | 부동소수점 오차 |
| $\sim10^{-5}$ | 실습에 무난 |

파라미터가 수십억이면 수치 미분으로 학습할 수 없습니다. 실무는 **해석적 미분 + Chain Rule + 역전파(Autograd)**입니다.

```python
import torch

w = torch.tensor(3.0, requires_grad=True)
L = (2 * w - 4) ** 2
L.backward()
print(w.grad)  # tensor(8.)  == L'(3)
```

Embedding · Attention · Softmax · LayerNorm도 **미분이 가능해야** 학습됩니다.

“미분 가능성”이 딥러닝 연산 선택의 숨은 조건입니다.

## 실습 11-1. NumPy 수치 미분

목표: $f(x)=3x^2$의 기울기를 근사하고 공식과 비교합니다.

```python
# lecture11_numpy_diff.py
import numpy as np

def f(x):
    return 3.0 * x ** 2

def numerical_diff(f, x, h=1e-5):
    return (f(x + h) - f(x)) / h

x = 2.0
approx = numerical_diff(f, x)
exact = 6.0 * x
print(approx, exact, abs(approx - exact))
```

배운 점: 수치 미분은 **검산 도구**이지 학습 엔진의 본체가 아닙니다.

## 실습 11-2. PyTorch 편미분

목표: 2변수 Loss의 편미분을 Autograd로 확인합니다.

```python
# lecture11_torch_partial.py
import torch

w1 = torch.tensor(2.0, requires_grad=True)
w2 = torch.tensor(1.0, requires_grad=True)
L = (w1 + w2 - 5.0) ** 2
L.backward()
print(w1.grad, w2.grad)  # -4, -4
```

손계산 $2(w_1+w_2-5)=-4$와 같습니다.

## 실습 11-3. 다변수 수치 vs 해석

목표: $f(x,y)=x^2+3xy+y^2$의 편미분을 수치로 검산합니다.

```python
# lecture11_partial_check.py
import numpy as np

def f(x, y):
    return x**2 + 3*x*y + y**2

def num_dx(x, y, h=1e-5):
    return (f(x + h, y) - f(x, y)) / h

def num_dy(x, y, h=1e-5):
    return (f(x, y + h) - f(x, y)) / h

x, y = 1.0, 2.0
print(num_dx(x, y), 2*x + 3*y)
print(num_dy(x, y), 3*x + 2*y)
```

오차가 $10^{-6}$ 미만이면 구현이 맞습니다.

## LLM에서는 어디에 사용될까?

$$
L=L(\theta),\quad
\theta=\{W^{(1)},b^{(1)},\ldots\}
$$

매 스텝 필요한 것은 모든 $i$에 대한 $\partial L/\partial\theta_i$입니다.

| 단계 | 내용 | 강의 |
|---|---|---|
| 미분/편미분 | 민감도 숫자 | 11 (이번) |
| Gradient | 편미분을 벡터로 | 12 |
| Chain Rule | 합성 경로 전파 | 14 |
| Backprop | 손·NumPy로 전파 | 17–18 |
| Autograd | 자동 편미분 | 20 |

Cross Entropy · Softmax · Linear · Attention 곱셈은 모두 미분 가능한 경로로 연결되어, 한 번의 `backward()`로 수백만 편미분이 채워집니다.

## 자주 하는 실수

1. 평균 변화율과 순간 변화율 혼동 ($h$가 크면 할선).
2. 편미분에서 다른 변수를 같이 움직임.
3. Loss↓ 방향을 미분 부호와 같게 읽음.
4. 합성함수인데 겉만 미분.
5. 수치 미분 $h$를 극단적으로 잡음.

## 핵심 요약

- 미분은 순간 민감도 $f'(x)$다.
- 부호는 증가/감소 방향, 크기는 민감도를 말한다.
- 편미분은 다변수에서 한 축만의 기울기다.
- LLM 학습은 $\partial L/\partial\theta_i$를 모아 파라미터를 옮기는 일이다.
- 수치 미분은 검증, Autograd/역전파는 확장 가능한 계산이다.

## 용어 사전

| 용어 | 설명 |
|---|---|
| Derivative | 순간 변화율 $f'(x)$ |
| Difference Quotient | $(f(x+h)-f(x))/h$ |
| Partial Derivative | 다른 변수 고정 미분 |
| Gradient | 편미분을 모은 벡터 (12강) |
| Linear Approximation | $f(x+h)\approx f+f'h$ |
| Numerical Differentiation | 작은 $h$로 근사 |
| Autograd | 자동 미분 |
| Loss $L$ | 예측과 정답의 차이 척도 |
| Parameter $\theta$ | 학습 가중치·편향 |
| Chain Rule | 합성함수 미분 (14강) |
| Backward | 역방향 기울기 전파 |
| Learning Rate $\eta$ | 한 걸음 크기 (12강) |
| Stationary Point | $f'=0$인 지점 |
| Differentiability | 미분이 정의됨 |

## 연습문제

### 기초

$f(x)=5x-2$의 도함수와 $f'(10)$은?

왜 LLM Loss에 “편미분”을 말해야 합니까?

### 계산

$f(x)=x^2$, $x=4$, $h=0.1$ 전방차분과 $f'(4)$를 비교하시오.

$f(u,v)=u^2v$의 $\partial f/\partial u$, $\partial f/\partial v$와 $(2,3)$에서의 값.

$L(w)=(3w-6)^2$의 $L'(w)$. $w=1$에서 Loss↓를 위해 $w$를?

### 코드

```python
import torch
w = torch.tensor(1.0, requires_grad=True)
L = (3 * w - 6) ** 2
L.backward()
print(w.grad)
```

출력은?

### 응용

$L(w)=(2w-4)^2$, $w=3$일 때 $L'$ 부호로 $w$를 어떻게 바꿀지 설명하시오.

Transformer 가중치 $W_{ij}$의 $\partial L/\partial W_{ij}$가 한 스텝에서 의미하는 바를 두 문장으로 쓰시오.

Softmax가 “거의 어디서나 미분 가능”해야 하는 이유를 한 문장으로 쓰시오.

---

## 정답 및 해설

### 기초

$f'=5$, $f'(10)=5$.

Loss가 수많은 파라미터의 함수이므로, 한 파라미터의 영향은 나머지를 고정한 편미분으로 말합니다.

### 계산

전방차분 $8.1$, 정확값 $8$.

$\partial f/\partial u=2uv$, $\partial f/\partial v=u^2$ → $(2,3)$에서 $12$, $4$.

$L'=18(w-2)$. $w=1$이면 $-18$ → $w$를 **키움**.

### 코드

`tensor(-18.)`

### 응용

$L'(3)=8>0$ → $w$를 줄임 ($3\to2$ 쪽).

$\partial L/\partial W_{ij}$는 그 원소만 아주 조금 키울 때 Loss 변화율입니다. 부호·크기로 이동 방향을 정합니다.

다음 토큰 확률 경로로 Loss 기울기가 흘러가려면 Softmax가 미분 가능해야 합니다.

## 다음 강의와 연결

이번 강의에서 “기울기라는 숫자”를 얻었습니다.
