# 11강. 미분과 편미분

## 이번 강에서 배우는 내용

- **Derivative(미분, 도함수)**의 직관과 정의
- 기본 미분 공식을 손으로 쓰기
- **Partial Derivative(편미분)**가 필요한 이유
- 다변수 함수에서 “한 변수만 움직일 때”의 기울기
- 이것이 왜 LLM의 Parameter 학습으로 이어지는지

## 왜 중요한가?

학습(training)이란 대략 다음입니다.

```text
Loss가 작아지도록 Parameter를 조금 움직인다
```

“어느 방향으로, 얼마나”를 알려면 **Loss가 Parameter에 대해 얼마나 민감한지**를 알아야 합니다.

그 민감도가 미분입니다.

미분을 “공식 암기”로만 지나면, `loss.backward()`가 무엇을 계산하는지 영원히 검게 남습니다.

이번 강의는 그 상자를 엽니다.

> **핵심**
>
> 미분 = 순간 변화율. 편미분 = 여러 파라미터 중 **하나만** 볼 때의 변화율.

## 선수 개념

- 함수 $f(x)$: 입력 $x$를 받아 출력 $f(x)$를 준다
- 일차·이차함수의 그래프 감각
- Scalar / Vector (9강)
- 내적·행렬곱 (10강)

극한의 엄밀한 $\varepsilon$-$\delta$ 정의는 필요하지 않습니다. “한없이 가깝게” 직관이면 충분합니다.

## 미분 (Derivative)

**Derivative(미분계수/도함수)**는 함수가 어떤 점에서 **순간적으로 얼마나 가파른지**를 나타내는 값입니다.

$$
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
$$

위 식을 **미분의 정의식**이라고 부릅니다.

- $h$: 아주 작은 입력 변화량
- $f(x+h)-f(x)$: 출력의 변화량
- 분수: “출력 변화 / 입력 변화” = 평균 변화율
- $h\to 0$: 간격을 한없이 줄여 **순간** 변화율로 만든다
- $f'(x)$: $x$에서의 미분계수. $\dfrac{df}{dx}$와 같은 뜻

왜 필요한가?

- $f'(x)>0$이면 그 근처에서 $x$를 키울 때 $f$도 커집니다.
- $f'(x)<0$이면 $x$를 키울 때 $f$는 작아집니다.
- $|f'(x)|$가 클수록 민감합니다.

학습에서는 “Loss를 줄이려면 Parameter를 어느쪽으로 밀까?”에 바로 쓰입니다.

**그림 11-1. 미분은 접선의 기울기**

![그림 11-1](images/fig11-01.svg)

### 표기법

$$
f'(x),\quad \frac{df}{dx},\quad \frac{d}{dx}f(x)
$$

다변수로 가면 편미분 기호 $\partial$를 씁니다.

### 기본 공식

$c$는 상수입니다.

| 함수 | 도함수 |
|---|---|
| $f(x)=c$ | $f'(x)=0$ |
| $f(x)=x$ | $f'(x)=1$ |
| $f(x)=cx$ | $f'(x)=c$ |
| $f(x)=x^n$ | $f'(x)=n x^{n-1}$ |
| $f(x)=e^x$ | $f'(x)=e^x$ |
| $f(x)=\ln x$ | $f'(x)=1/x$ ($x>0$) |

선형성:

$$
\frac{d}{dx}\big(af(x)+bg(x)\big) = a f'(x) + b g'(x)
$$

곱의 미분·합성함수 미분(Chain Rule)은 14강에서 본격적으로 다룹니다. 미리 한 줄만:

$$
\frac{d}{dx}f(g(x)) = f'(g(x))\cdot g'(x)
$$

## 직관 — 산의 기울기

높이를 $f(x)$, 발밑 기울기를 $f'(x)$로 보면:

```text
기울기 +2  → 오른쪽으로 한 걸음이면 높이 약 +2
기울기 -3  → 오른쪽으로 한 걸음이면 높이 약 -3
기울기  0  → 평지 (국소 최대/최소 후보)
```

선형 근사:

$$
f(x+h) \approx f(x) + f'(x)\, h
$$

아주 작은 $h$에 대해, 곡선 대신 **접선**으로 근사합니다.

딥러닝의 파라미터 업데이트도 이 1차 근사 감각 위에 있습니다.

## 작은 숫자로 직접 계산하기

### 정의로 미분 — $f(x)=x^2$

$x=3$에서:

$$
f'(3)
=
\lim_{h\to 0}\frac{(3+h)^2 - 9}{h}
=
\lim_{h\to 0}(6 + h)
=
6
$$

공식으로도 $f'(x)=2x$이므로 $f'(3)=6$. 일치합니다.

수치로 $h=0.001$:

$$
\frac{(3.001)^2 - 9}{0.001} = 6.001
$$

이미 6에 가깝습니다.

### 직선 $f(x)=3x+1$

$$
f'(x)=3
$$

어디서든 기울기가 3입니다. $x$를 1 키우면 $f$는 정확히 3 커집니다.

### Loss처럼 보이는 1변수 예

예측 $\hat{y}=wx$, 정답 $y$, 제곱오차

$$
L(w) = (wx - y)^2
$$

$x=2$, $y=4$로 고정하면

$$
L(w)=(2w-4)^2 = 4(w-2)^2
$$

$$
L'(w)=8(w-2)
$$

- $w=2$이면 $L'=0$ (이미 정답)
- $w=3$이면 $L'=8>0$ → $w$를 키우면 Loss가 커짐 → **줄이려면 $w$를 줄여야** 함
- $w=1$이면 $L'=-8<0$ → $w$를 키우면 Loss가 작아짐

이 한 줄이 12강 Gradient Descent의 씨앗입니다.

> ⚠️ **주의**
>
> Loss를 줄이려면 보통 파라미터가 미분의 **반대** 방향으로 움직입니다. ($w \leftarrow w - \eta L'(w)$)

## 편미분 (Partial Derivative)

입력이 여러 개일 때, **한 변수만** 움직이고 나머지는 상수로 둔 채 미분하는 것이 **Partial Derivative(편미분)**입니다.

$$
\frac{\partial f}{\partial x}
=
\lim_{h\to 0}
\frac{f(x+h,\ y) - f(x,y)}{h}
$$

$$
\frac{\partial f}{\partial y}
=
\lim_{h\to 0}
\frac{f(x,\ y+h) - f(x,y)}{h}
$$

- $\partial$: 편미분 기호
- $\frac{\partial f}{\partial x}$: $y$를 고정한 채 $x$ 방향 기울기

왜 필요한가?

- LLM Parameter는 하나가 아닙니다. 수백만~수천억 개입니다.
- Loss는 그 모든 파라미터의 함수입니다.
- “$W_{17}$만 조금 바꾸면 Loss가 어떻게 되나?”가 곧 $\partial L / \partial W_{17}$입니다.

**그림 11-2. 편미분은 한 축만의 기울기**

![그림 11-2](images/fig11-02.svg)

> 💡 **팁**
>
> 초보 단계에서는 “입력이 여러 개면 $\partial$”라고 기억해도 실무에 충분합니다.

### 다변수 예 — $f(x,y)=x^2 + 3xy + y^2$

$$
\frac{\partial f}{\partial x} = 2x + 3y, \quad
\frac{\partial f}{\partial y} = 3x + 2y
$$

점 $(1, 2)$에서 $\partial f/\partial x=8$, $\partial f/\partial y=7$.

의미:

- $x$만 $+0.01$ → $f$는 약 $0.08$ 증가
- $y$만 $+0.01$ → $f$는 약 $0.07$ 증가

수치 확인: $f(1,2)=11$, $f(1.01,2)=11.0801$. 증가량 $0.0801\approx 0.08$.

### 2파라미터 Loss

입력 $x=1$, 정답 $y=5$,

$$
\hat{y} = w_1 + w_2, \quad
L(w_1, w_2) = (w_1 + w_2 - 5)^2
$$

$$
\frac{\partial L}{\partial w_1}
=
\frac{\partial L}{\partial w_2}
=
2(w_1 + w_2 - 5)
$$

$w_1=2$, $w_2=1$이면 $\hat{y}=3$, $L=4$, 편미분은 각 $-4$입니다.

두 파라미터를 **같은 방향·같은 크기**로 밀면 Loss가 줄어듭니다. 12강에서 이를 벡터로 묶어 **Gradient**라 부릅니다.

## 수치 미분과 Autograd 맛보기

수치 미분(전방차분):

$$
f'(x) \approx \frac{f(x+h)-f(x)}{h}
$$

검증에는 좋지만, 파라미터가 수십억이면 한 번씩 흔들 수 없습니다.

그래서 실무는 **해석적 미분 + Chain Rule + 역전파(Autograd)**를 씁니다.

```python
import torch

w = torch.tensor(3.0, requires_grad=True)
L = (2 * w - 4) ** 2
L.backward()
print(w.grad)  # tensor(8.)  ← L'(3)=8
```

`backward()`가 내부적으로 미분(정확히는 Chain Rule로 편미분을 전파)을 수행합니다.

## 실습 11-1. NumPy 수치 미분

목표: 정의식으로 $f(x)=3x^2$의 기울기를 근사하고 공식과 비교합니다.

```python
# lecture11_numpy_numerical_diff.py
import numpy as np

def f(x):
    return 3.0 * x ** 2

def numerical_diff(f, x, h=1e-5):
    return (f(x + h) - f(x)) / h

x = 2.0
approx = numerical_diff(f, x)
exact = 6.0 * x  # f'(x)=6x
print("approx:", approx)
print("exact :", exact)
print("error :", abs(approx - exact))
```

$h=10^{-5}$ 근처면 오차가 매우 작습니다. 너무 크면 할선 오차, 너무 작으면 부동소수점 오차가 납니다.

배운 점: 수치 미분은 **검산 도구**, 학습 엔진의 본체가 아닙니다.

## 실습 11-2. PyTorch로 편미분 확인

목표: 2변수 Loss의 편미분을 Autograd로 확인합니다.

```python
# lecture11_torch_partial.py
import torch

w1 = torch.tensor(2.0, requires_grad=True)
w2 = torch.tensor(1.0, requires_grad=True)
y_hat = w1 + w2
L = (y_hat - 5.0) ** 2
L.backward()
print(w1.grad, w2.grad)  # 둘 다 -4.
```

손계산 $\partial L/\partial w_1 = 2(w_1+w_2-5)=-4$와 같습니다.

`requires_grad=True`인 텐서만 기울기가 쌓입니다.

## LLM에서는 어디에 사용될까?

LLM의 Loss $L$는 모든 Parameter $\theta$의 함수입니다.

$$
L = L(\theta), \quad
\theta = \{W^{(1)}, b^{(1)}, W^{(2)}, \ldots\}
$$

학습에 필요한 것은

$$
\frac{\partial L}{\partial \theta_i}
\quad \text{for every } \theta_i
$$

입니다.

한 파라미터씩 수치 미분하면 너무 느립니다.

그래서 **해석적 미분 + Chain Rule + 역전파**로 한 번의 후진 계산에 모든 편미분을 구합니다.

Embedding·Attention 안의 곱셈·덧셈·Softmax·LayerNorm도 미분이 가능해야 학습이 됩니다.

“미분 가능성”이 딥러닝 연산 선택의 숨은 조건입니다.

| 단계 | 하는 일 | 관련 강 |
|---|---|---|
| 미분/편미분 | 민감도 숫자 | 11강 (이번) |
| Gradient | 편미분을 벡터로 묶음 | 12강 |
| Chain Rule | 합성 경로로 전파 | 14강 |
| Autograd | 자동으로 편미분 계산 | 20강 |

## 자주 하는 실수

1. 평균 변화율과 순간 변화율을 혼동한다 — $h$가 크면 할선이다.
2. 편미분에서 다른 변수를 같이 움직인다 — $\partial f/\partial x$에서 $y$는 고정이다.
3. $f'$의 부호를 업데이트 방향과 반대로 읽는다 — Loss↓는 보통 미분의 반대 방향.
4. 합성함수인데 겉만 미분한다 — $(2x-1)^2$은 Chain Rule(또는 전개)이 필요하다.
5. 수치 미분의 $h$를 너무 크거나 작게 잡는다 — $10^{-5}$ 근처가 실습에 무난하다.

## 핵심 요약

- 미분은 “입력 변화에 대한 출력의 순간 민감도”다.
- $f'(x)>0$이면 $x$ 증가 시 $f$ 증가 경향, $<0$이면 감소 경향.
- 편미분은 다변수 함수에서 한 변수만의 민감도이다.
- LLM 학습은 결국 $\partial L/\partial \theta_i$를 구해 파라미터를 움직이는 일이다.
- 수치 미분은 검증 도구, Autograd/역전파는 확장 가능한 계산 도구다.

## 용어 사전

| 용어 | 설명 |
|---|---|
| Derivative (미분/도함수) | 순간 변화율 $f'(x)$ |
| Difference Quotient | $(f(x+h)-f(x))/h$ 평균 변화율 |
| Partial Derivative (편미분) | 다른 변수를 고정한 채 한 변수로 미분 |
| Gradient (예고) | 모든 편미분을 모은 벡터 (12강) |
| Linear Approximation | $f(x+h)\approx f(x)+f'(x)h$ |
| Numerical Differentiation | 작은 $h$로 미분을 근사 |
| Autograd | 자동 미분 시스템 |
| Loss $L$ | 예측이 정답과 얼마나 다른지 |
| Parameter $\theta$ | 학습되는 가중치·편향 등 |
| Chain Rule (예고) | 합성함수 미분 규칙 (14강) |
| Backward | 역방향으로 기울기를 전파 |
| Sensitivity | 출력이 입력에 얼마나 민감한지 |

## 연습문제

### 기초

$f(x)=5x-2$의 도함수는? $f'(10)$은?

왜 LLM Loss에 대해 “그냥 미분”이 아니라 “편미분”을 말해야 하는가? (한두 문장)

### 계산

$f(x)=x^2$에서 $x=4$, $h=0.1$일 때 전방차분 근사값을 구하고 $f'(4)$와 비교하시오.

$f(u,v)=u^2 v$에서 $\partial f/\partial u$, $\partial f/\partial v$를 쓰시오. $(u,v)=(2,3)$에서의 값도 구하시오.

### 코드

다음 코드 실행 후 `w.grad`는?

```python
import torch
w = torch.tensor(1.0, requires_grad=True)
L = (3 * w - 6) ** 2
L.backward()
print(w.grad)
```

### 응용

$L(w)=(2w-4)^2$, $w=3$일 때 $L'(w)$의 부호를 보고, Loss를 줄이려면 $w$를 어떻게 바꿔야 하는지 설명하시오.

Transformer의 Linear 가중치 $W$ 한 원소 $W_{ij}$에 대해, “편미분 $\partial L/\partial W_{ij}$”가 학습 한 스텝에서 의미하는 바를 두 문장으로 쓰시오.

---

## 정답 및 해설

### 기초

$f'(x)=5$. 어디서든 $f'(10)=5$.

Loss가 수많은 파라미터의 함수이기 때문입니다. 한 파라미터의 영향을 말할 때는 나머지를 고정한 편미분이 자연스럽습니다.

### 계산

전방차분: $((4.1)^2 - 16)/0.1 = 8.1$. 정확한 $f'(4)=8$. 근사가 약간 큽니다.

$\partial f/\partial u = 2uv$, $\partial f/\partial v = u^2$. $(2,3)$에서 $12$, $4$.

### 코드

$L'(w)=2(3w-6)\cdot 3=18(w-2)$. $w=1$이면 $-18$. → `tensor(-18.)`

### 응용

$L'(3)=8>0$이므로 $w$를 키우면 Loss가 커집니다. 줄이려면 $w$를 감소시킵니다 ($3\to 2$ 쪽).

$\partial L/\partial W_{ij}$는 그 가중치만 아주 조금 키울 때 Loss가 얼마나 변하는지를 말합니다. 부호·크기를 보고 $W_{ij}$를 어느 쪽으로 얼마나 옮길지 정합니다.
