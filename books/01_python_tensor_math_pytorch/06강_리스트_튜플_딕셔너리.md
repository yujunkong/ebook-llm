# 6강. 리스트, 튜플, 딕셔너리
## 이번 강에서 배우는 내용

- list, tuple, dict, set의 차이를 설명한다
- 인덱싱·슬라이싱·순회로 시퀀스를 다룬다
- dict로 키-값 매핑을 만들고 조회한다
- (가볍게) list comprehension을 읽거나 작성한다
- vocabulary(단어↔ID) 매핑이 왜 dict 형태인지 이해한다

## 왜 중요한가?
LLM의 입력은 대개 “값 하나”가 아니라 **값들의 나열**이다.

```text
텍스트
 → 토큰 리스트
   → 토큰 ID 리스트
     → 배치(여러 문장의 ID 리스트들)
```

또한 모델이 단어를 숫자로 다루려면 **어휘 사전(vocabulary)**이 필요하다.

```text
"날씨가" → 1523
1523 → "날씨가"
```

이 양방향 매핑의 자연스러운 파이썬 표현이 dict이다.

자료구조를 탄탄히 익히지 않으면, 이후 Tokenizer·Embedding·배치 코드를 읽을 때 계속 발목을 잡힌다.

## 선수 개념
### 2.1 Collection

**Collection(컬렉션)**은 여러 원소를 담는 자료구조의 총칭이다.

Python 기본 컬렉션:

| 종류 | 특징 | 예 |
|---|---|---|
| list | 순서가 있고 변경 가능 | `[1, 2, 3]` |
| tuple | 순서가 있고 변경 불가 | `(1, 2, 3)` |
| dict | 키→값 매핑 | `{"a": 1}` |
| set | 중복 없는 집합 | `{1, 2, 3}` |

### 2.2 Mutable vs Immutable

**Mutable(가변)**은 생성 후 내용을 바꿀 수 있다. list, dict, set이 대표적이다.  
**Immutable(불변)**은 생성 후 내용을 바꿀 수 없다. tuple, str, int가 대표적이다.

이 구분은 “실수로 데이터가 바뀌는가”, “딕셔너리 키가 될 수 있는가”에서 중요하다.

## 핵심 개념
### 3.1 list — 순서 있는 가변 시퀀스

**list(리스트)**는 순서가 있는 값들의 목록이다. 대괄호로 만든다.

```python
tokens = ["오늘", "날씨가", "좋다"]
ids = [101, 2048, 87]
```

왜 필요한가?

- 토큰 시퀀스처럼 **순서가 의미**인 데이터를 담는다
- 원소 추가·수정·삭제가 쉽다

주요 연산:

```python
tokens = ["오늘", "날씨가"]
tokens.append("좋다")      # 끝에 추가
tokens[0] = "내일"         # 수정
print(len(tokens))         # 길이
print(tokens[1])           # 인덱싱 (0부터)
print(tokens[-1])          # 마지막 원소
print(tokens[0:2])         # 슬라이싱 → ["내일", "날씨가"]
```

슬라이싱 `a[start:stop]`에서 `stop`은 포함되지 않는다.

리스트는 중첩할 수 있다. 배치 표현에 자주 등장한다.

```python
batch = [
    [101, 22, 9],
    [101, 8],
]
```

실제 학습에서는 길이를 맞추기 위해 padding을 넣지만, 원형은 “리스트의 리스트”이다.

### 3.2 tuple — 순서 있는 불변 시퀀스

**tuple(튜플)**은 리스트와 비슷하지만 변경할 수 없다.

```python
shape = (2, 3, 4)
pair = ("bos", 0)
```

왜 쓰는가?

1. “이 값은 고정”이라는 의도 표현
2. dict의 키로 사용 가능 (list는 불가)
3. 함수가 여러 값을 반환할 때 자연스럽다

```python
def min_max(xs: list[float]) -> tuple[float, float]:
    return min(xs), max(xs)

lo, hi = min_max([1.0, 5.0, 2.0])
```

텐서의 shape `(batch, seq, hidden)` 같은 정보는 튜플로 다루는 경우가 많다.

### 3.3 dict — 키에서 값으로의 매핑

**dict(dictionary, 딕셔너리)**는 키(key)를 값(value)에 대응시키는 자료구조이다.

```python
vocab = {
    "<pad>": 0,
    "<unk>": 1,
    "오늘": 2,
    "날씨가": 3,
    "좋다": 4,
}
```

왜 필요한가?

- “이름 → 번호” 변환이 $O(1)$에 가깝게 빠르다
- 설정, 메트릭, JSON 객체와 구조가 잘 맞는다

조회·수정:

```python
print(vocab["오늘"])          # 2
print(vocab.get("비", 1))     # 없으면 기본값 1 (<unk>)
vocab["맑다"] = 5             # 추가/수정
print("좋다" in vocab)        # True
print(list(vocab.keys()))
print(list(vocab.values()))
```

`dict[key]`는 키가 없으면 에러, `get`은 기본값을 줄 수 있다.  
Tokenizer에서 미등록 토큰을 `<unk>`로 보낼 때 `get` 패턴이 자주 나온다.

### 3.4 set — 중복 없는 집합

**set(세트)**는 중복을 허용하지 않는 집합이다. 순서는 보장하지 않는 것으로 생각하는 편이 안전하다. (구현·버전에 따라 삽입 순서를 보존하는 경우도 있으나, “순서 있는 시퀀스”가 필요하면 list를 쓴다.)

```python
unique_tokens = {"오늘", "날씨가", "오늘"}
print(unique_tokens)  # {"오늘", "날씨가"}
```

용도:

- 빠른 포함 여부 검사
- 중복 제거
- 합집합·교집합

```python
a = {"a", "b", "c"}
b = {"b", "c", "d"}
print(a & b)  # 교집합
print(a | b)  # 합집합
```

말뭉치에서 고유 토큰 수를 대략 볼 때 유용하다.

### 3.5 순회 패턴

```python
tokens = ["오늘", "날씨가", "좋다"]

for t in tokens:
    print(t)

for i, t in enumerate(tokens):
    print(i, t)

vocab = {"오늘": 2, "좋다": 4}
for k, v in vocab.items():
    print(k, "→", v)
```

`enumerate`는 인덱스가 필요할 때, `items`는 키와 값이 모두 필요할 때 쓴다.

### 3.6 list comprehension (가볍게)

**List Comprehension(리스트 컴프리헨션)**은 리스트를 짧게 만드는 문법이다.

```python
ids = [2, 3, 4]
squares = [x * x for x in ids]
print(squares)  # [4, 9, 16]

# 조건 포함
even = [x for x in ids if x % 2 == 0]
```

가독성이 떨어질 정도로 길게 쓰지 않는다.  
초보 단계에서는 “읽을 수 있으면” 충분하고, 복잡한 로직은 일반 `for`가 낫다.

dict comprehension도 비슷하다.

```python
tokens = ["오늘", "날씨가", "좋다"]
vocab = {t: i for i, t in enumerate(tokens, start=2)}
```

## 직관적으로 이해하기
| 구조 | 직관 | LLM 비유 |
|---|---|---|
| list | 줄 서 있는 사람들 | 토큰 시퀀스 |
| tuple | 이름표가 고정된 좌표 | `(batch, length)` shape |
| dict | 사물함(열쇠→내용) | token ↔ id vocabulary |
| set | 중복 없는 명단 | 고유 토큰 집합 |

특히 dict는 이 책 전체에서 반복해서 등장한다.

```text
문자열 토큰  --dict-->  정수 ID  --모델-->  점수  --dict/list-->  다시 문자열
```

## 작은 숫자 예제 — 미니 Vocabulary
말뭉치가 다음뿐이라고 가정한다.

```text
오늘 날씨가 좋다
오늘 기분이 좋다
```

1. 공백 토큰화
2. 등장 순으로 ID 부여 (`<pad>=0`, `<unk>=1` 예약)
3. 문장을 ID 리스트로 변환

손으로 계산:

| 토큰 | ID |
|---|---:|
| \<pad\> | 0 |
| \<unk\> | 1 |
| 오늘 | 2 |
| 날씨가 | 3 |
| 좋다 | 4 |
| 기분이 | 5 |

문장 `"오늘 날씨가 좋다"` → `[2, 3, 4]`  
문장 `"오늘 비가 좋다"` → `[2, 1, 4]` (`비`는 미등록 → `<unk>`)

## 코드로 구현하기
```python
# mini_vocab.py
# 목적: list/dict로 아주 작은 vocabulary를 만든다.

from __future__ import annotations

def build_vocab(corpus: list[str]) -> dict[str, int]:
    vocab = {"<pad>": 0, "<unk>": 1}
    for line in corpus:
        for tok in line.split():
            if tok not in vocab:
                vocab[tok] = len(vocab)
    return vocab

def encode(text: str, vocab: dict[str, int]) -> list[int]:
    unk = vocab["<unk>"]
    return [vocab.get(tok, unk) for tok in text.split()]

def decode(ids: list[int], vocab: dict[str, int]) -> list[str]:
    # id → token 역매핑
    id2tok = {i: t for t, i in vocab.items()}
    return [id2tok.get(i, "<unk>") for i in ids]

if __name__ == "__main__":
    corpus = [
        "오늘 날씨가 좋다",
        "오늘 기분이 좋다",
    ]
    vocab = build_vocab(corpus)
    ids = encode("오늘 비가 좋다", vocab)
    print("vocab:", vocab)
    print("ids:", ids)
    print("decode:", decode(ids, vocab))
```

실행 결과 예:

```text
vocab: {'<pad>': 0, '<unk>': 1, '오늘': 2, '날씨가': 3, '좋다': 4, '기분이': 5}
ids: [2, 1, 4]
decode: ['오늘', '<unk>', '좋다']
```

이 코드가 2권 Tokenizer의 축소판이다.  
실제로는 BPE 등 더 정교한 분할을 쓰지만, **“리스트로 시퀀스를 담고, dict로 매핑한다”**는 뼈대는 같다.

## LLM에서는 어디에 사용될까?
| 자료구조 | LLM에서의 역할 |
|---|---|
| list[str] | 토큰 문자열 시퀀스 |
| list[int] | 토큰 ID 시퀀스 |
| list[list[int]] | 배치 (문장들의 ID) |
| dict[str, int] | token → id |
| dict[int, str] | id → token |
| tuple[int, ...] | 텐서 shape, 설정 묶음 |
| set | 특수 토큰 집합, 금지어 목록 등 |

Hugging Face Tokenizer도 사용자 입장에서는 결국:

```python
encoded = tokenizer("오늘 날씨가 좋다")
# input_ids 같은 정수 리스트(또는 텐서)를 얻음
```

내부 어디선가 vocabulary lookup이 일어난다. 6강에서 dict를 배우는 이유는 그 lookup의 감각을 먼저 갖기 위해서다.

### 실습 3 — 미니 배치 패딩(개념)

길이가 다른 두 시퀀스

```python
[[2, 3, 4], [2, 5]]
```

를 길이 3으로 맞추기 위해 짧은 쪽 끝에 `0`(`<pad>`)을 넣어 본다.  
(중첩 리스트를 직접 수정)

## 자주 하는 실수
1. **인덱스를 1부터라고 생각한다**  
   Python은 0부터다. 첫 토큰은 `tokens[0]`.

2. **list와 tuple을 아무렇게나 섞는다**  
   변경이 필요하면 list, 고정 묶음·dict 키면 tuple.

3. **dict 키 존재 여부를 안 보고 바로 접근한다**  
   미등록 토큰에서 `KeyError`가 난다. Tokenizer라면 `get(..., unk_id)`.

4. **list를 dict 키로 쓴다**  
   가변 객체는 키가 될 수 없다. tuple로 변환하거나 다른 키를 설계한다.

5. **컴프리헨션을 과하게 중첩한다**  
   두 겹을 넘기면 읽기 어려워진다. 일반 루프로 푼다.

## 핵심 요약
- list는 순서가 있는 가변 시퀀스, tuple은 불변 시퀀스이다
- dict는 키-값 매핑이며 vocabulary의 기본 형태이다
- set은 중복 없는 집합으로 포함 검사·고유값에 유용하다
- 인덱싱·슬라이싱·순회·컴프리헨션으로 컬렉션을 다룬다
- 토큰 시퀀스와 어휘 사전은 이후 LLM 파이프라인의 입구이다

## 용어 사전
| 용어 | 의미 |
|---|---|
| list | 순서 있는 가변 시퀀스 |
| tuple | 순서 있는 불변 시퀀스 |
| dict | 키→값 매핑 |
| set | 중복 없는 집합 |
| Indexing / Slicing | 위치·구간으로 원소 접근 |
| Vocabulary | 토큰과 ID의 대응표 |
| `<unk>` | 미등록 토큰용 특수 심볼 |
| List Comprehension | 리스트를 압축 표기로 생성하는 문법 |
| Mutable / Immutable | 변경 가능 / 변경 불가 |
