# 10강. 선형대수 기초 — 내적과 행렬곱

## 이번 강에서 배우는 내용

- **Dot Product(내적)**의 정의 · 기하 의미 · 코사인 유사도
- **Matrix Multiplication(행렬곱)**을 한 칸씩 손계산하는 법
- $AB \neq BA$가 되는 이유 (작은 숫자로 확인)
- Linear Layer $y = Wx + b$ / $y = xW + b$ 관례
- NumPy · PyTorch의 `@`와 `*` 차이
- Attention 점수 $QK^\top$와 배치 Shape `(B,T,d)`

## 왜 중요한가?

딥러닝 연산의 대부분은 결국 한 문장으로 압축됩니다.

```text
곱하고 더한다. (multiply-add)
```

내적은 대응 성분을 곱한 뒤 전부 더합니다.

행렬곱은 그 내적을 표 형태로 늘어놓습니다.

Convolution과 Attention도 구현 깊숙한 곳에서는 거대한 행렬곱(또는 그에 상응하는 연산)으로 돌아갑니다.

GPU가 빠른 이유 중 하나도, 이 규칙적인 곱-합을 병렬로 잘 처리하기 때문입니다.

> **핵심**
>
> 10강을 끝내면 Embedding 다음의 변환과 Attention 점수표를 **같은 언어(내적·행렬곱·Shape)**로 읽을 수 있습니다.

## 선수 개념

- Vector / Matrix / Shape (9강)
- 곱셈과 덧셈
- NumPy 배열 생성 (8강)

아직 필요하지 않은 것:

- 고유값, 행렬식, QR 분해
- 미분 (11강 이후)

이 책은 LLM에 필요한 선형대수만, **계산 가능한 최소 세트**로 가져갑니다.

## 내적 (Dot Product)

**Dot Product(내적, 스칼라곱)**는 같은 길이의 두 벡터에서, 대응 성분을 곱해 모두 더한 **Scalar**입니다.

$$
\mathbf{a} = [a_1,\ a_2,\ \ldots,\ a_n], \quad
\mathbf{b} = [b_1,\ b_2,\ \ldots,\ b_n]
$$

$$
\mathbf{a} \cdot \mathbf{b}
=
\sum_{i=1}^{n} a_i b_i
=
a_1 b_1 + a_2 b_2 + \cdots + a_n b_n
$$

위 식을 **내적 공식**이라고 부릅니다.

- 결과 Shape: Scalar (숫자 하나)
- 전제: 두 벡터 길이가 같아야 함

왜 필요한가?

- “두 방향이 얼마나 같은 쪽을 보는가”를 숫자로 요약합니다.
- Embedding 공간에서 비슷한 단어는 내적이 큰 경향이 있습니다.
- 행렬곱의 **한 칸**이 곧 내적입니다.

### 기하 직관과 그림

2D에서

$$
\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \|\mathbf{b}\| \cos \theta
$$

- $\|\mathbf{a}\| = \sqrt{a_1^2+\cdots+a_n^2}$: 길이(노름)
- $\theta$: 두 벡터 사이 각
- $\cos\theta$: 같은 방향 → 1, 직각 → 0, 반대 → $-1$

**그림 10-1. 벡터의 방향과 내적**

![그림 10-1](images/fig10-01.svg)

LLM에서는 차원이 수백~수천이지만, “비슷한 표현끼리 큰 점수”라는 직관은 그대로입니다.

### 작은 숫자 — 내적

$$
\mathbf{a}=[1,\ 2],\quad \mathbf{b}=[3,\ 4]
$$

$$
\mathbf{a}\cdot\mathbf{b}=1\cdot3+2\cdot4=11
$$

$$
\mathbf{u}=[1,\ 0,\ -1],\quad \mathbf{v}=[2,\ 5,\ 2]
$$

$$
\mathbf{u}\cdot\mathbf{v}=2+0-2=0
$$

내적 0이면 (유클리드 기하에서) **직교**입니다. “독립적인 방향” 감각입니다.

### 코사인 유사도 (정규화 후 내적)

길이가 다르면 내적만으로 “방향 유사도”를 읽기 어렵습니다.

$$
\cos\theta
=
\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\| \|\mathbf{b}\|}
$$

예: $\mathbf{a}=[3,\ 0]$, $\mathbf{b}=[1,\ 1]$

$$
\|\mathbf{a}\|=3,\quad
\|\mathbf{b}\|=\sqrt{2},\quad
\mathbf{a}\cdot\mathbf{b}=3
$$

$$
\cos\theta=\frac{3}{3\sqrt{2}}=\frac{1}{\sqrt{2}}\approx 0.707
$$

> 💡 **팁**
>
> 검색·임베딩 비교에서는 길이를 1로 맞춘 뒤 내적(=코사인)을 쓰는 경우가 많습니다.

## 행렬곱 (Matrix Multiplication)

**행렬곱** $C=AB$의 한 칸은 **행·열 내적**입니다.

$$
(AB)_{ik}=\sum_{j} A_{ij} B_{jk}
$$

Shape 규칙:

```text
A: (m, n)
B: (n, p)
AB: (m, p)
```

가운데 $n$이 같아야 합니다.

**그림 10-2. 행렬곱은 행·열 내적**

![그림 10-2](images/fig10-02.svg)

> ⚠️ **주의**
>
> `(3,4) @ (3,2)`는 실패합니다. 가운데 차원이 같아야 합니다.

### 2×2를 한 칸씩

$$
A=\begin{bmatrix}1&2\\3&4\end{bmatrix},\quad
B=\begin{bmatrix}5&6\\7&8\end{bmatrix}
$$

$$
C=\begin{bmatrix}19&22\\43&50\end{bmatrix}
$$

검증: $C_{11}=1\cdot5+2\cdot7=19$, $C_{22}=3\cdot6+4\cdot8=50$.

### 2×3 @ 3×2

$$
A=\begin{bmatrix}1&2&0\\0&1&1\end{bmatrix}\ (2\times3),\quad
B=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}\ (3\times2)
$$

$$
AB=\begin{bmatrix}
1\cdot1+2\cdot0+0\cdot1 & 1\cdot0+2\cdot1+0\cdot1 \\
0\cdot1+1\cdot0+1\cdot1 & 0\cdot0+1\cdot1+1\cdot1
\end{bmatrix}
=
\begin{bmatrix}1&2\\1&2\end{bmatrix}
$$

결과 Shape는 `(2, 2)`입니다.

### $AB \neq BA$ — 작은 숫자로 확인

$$
A=\begin{bmatrix}1&1\\0&1\end{bmatrix},\quad
B=\begin{bmatrix}0&1\\1&0\end{bmatrix}
$$

$$
AB=\begin{bmatrix}1&1\\1&0\end{bmatrix},\quad
BA=\begin{bmatrix}0&1\\1&1\end{bmatrix}
$$

같지가 않습니다. 행렬곱은 **교환법칙이 성립하지 않습니다.**

> 📘 **심화**
>
> Attention의 $QK^\top$와 $KQ^\top$도 일반적으로 다릅니다. 행·열 역할이 바뀌기 때문입니다.

## Linear Layer — $Wx+b$와 $xW+b$

**Linear Layer**의 기본식:

$$
\mathbf{y}=W\mathbf{x}+\mathbf{b}
$$

코드·배치 처리에서는 행벡터 관례가 흔합니다.

$$
\mathbf{y}=\mathbf{x}W+\mathbf{b}
$$

이때 $W$ Shape는 `(d_in, d_out)`입니다. **수식과 코드의 배치만 일치하면** 됩니다.

**그림 10-3. Linear Layer y = xW + b**

![그림 10-3](images/fig10-03.svg)

예: $\mathbf{x}=[1,\ 0]$,  
$W=\begin{bmatrix}1&3&5\\2&4&6\end{bmatrix}$, $\mathbf{b}=[10,\ 20,\ 30]$

$$
\mathbf{x}W=[1,\ 3,\ 5],\quad
\mathbf{y}=[11,\ 23,\ 35]
$$

왜 필요한가?

- Embedding 다음의 거의 모든 변환이 Linear입니다.
- Q/K/V projection, MLP, LM Head가 모두 $W$ 곱입니다.

## 행렬곱이 아닌 것들

### Hadamard (요소별 곱)

$$
\begin{bmatrix}1&2\\3&4\end{bmatrix}
\odot
\begin{bmatrix}5&6\\7&8\end{bmatrix}
=
\begin{bmatrix}5&12\\21&32\end{bmatrix}
$$

| 연산 | NumPy/PyTorch | 의미 |
|---|---|---|
| 내적/행렬곱 | `@`, `matmul` | 행·열 합 |
| 요소별 곱 | `*` | 같은 위치끼리 |

Attention **점수**는 `@`입니다. 활성화·게이트의 요소별 곱은 `*`입니다.

### 전치

$K^\top$는 행과 열을 바꿉니다. $QK^\top$의 $^\top$가 바로 이 연산입니다.

## Attention 점수 — $QK^\top$ 미니 버전

토큰 2개, 차원 2:

$$
Q=\begin{bmatrix}1&0\\0&1\end{bmatrix},\quad
K=\begin{bmatrix}1&2\\3&4\end{bmatrix}
$$

$$
QK^\top=\begin{bmatrix}1&3\\2&4\end{bmatrix}
$$

| 칸 | 의미 | 값 |
|---|---|---:|
| (0,0) | 토큰0 쿼리 ↔ 토큰0 키 | 1 |
| (0,1) | 토큰0 쿼리 ↔ 토큰1 키 | 3 |
| (1,0) | 토큰1 쿼리 ↔ 토큰0 키 | 2 |
| (1,1) | 토큰1 쿼리 ↔ 토큰1 키 | 4 |

이 표가 “어디에 주의를 기울일지”의 점수 초안입니다. 스케일·Softmax는 37~38강에서 이어집니다.

### 배치 Shape (LLM 감각)

```text
x:      (B, T, d)
W:      (d, d_out)
x @ W:  (B, T, d_out)
```

예: $B=2$, $T=16$, $d=768$, $d_{\mathrm{out}}=768$이면 Q projection 출력은 `(2, 16, 768)`입니다.

어휘 크기 $V\approx 50000$인 LM Head는 `(d, V)` 곱으로 logits `(B, T, V)`를 만듭니다.

> 💡 **팁**
>
> “숫자 성능”은 환경마다 달라 임의로 적지 않습니다. 대신 **Shape와 연산 종류**를 먼저 고정하세요.

## 실습 10-1. NumPy — 내적 · 행렬곱 · Hadamard

목표: `@`와 `*`의 차이를 숫자로 확인합니다.

```python
# lecture10_numpy_ops.py
import numpy as np

a = np.array([1.0, 2.0])
b = np.array([3.0, 4.0])
print("dot:", a @ b)  # 11.0

A = np.array([[1.0, 2.0], [3.0, 4.0]])
B = np.array([[5.0, 6.0], [7.0, 8.0]])
print("matmul:\n", A @ B)
print("hadamard:\n", A * B)

# Shape 판정
X = np.zeros((2, 3, 4))
W = np.zeros((4, 5))
print((X @ W).shape)  # (2, 3, 5)
```

`X @ W`는 뒤 축만 행렬곱합니다. LLM 배치 처리와 같은 규칙입니다.

배운 점: **기호 하나로 연산이 갈립니다.**

## 실습 10-2. PyTorch — Linear와 $QK^\top$

목표: `nn.Linear`와 점수 행렬 Shape를 확인합니다.

```python
# lecture10_torch_linear_qk.py
import torch
import torch.nn as nn

x = torch.randn(2, 16, 32)          # (B, T, d)
linear = nn.Linear(32, 64)
y = linear(x)
print(y.shape)                      # (2, 16, 64)

Q = torch.randn(2, 16, 8)
K = torch.randn(2, 16, 8)
scores = Q @ K.transpose(-2, -1)
print(scores.shape)                 # (2, 16, 16)
```

`scores`의 마지막 두 축 `(T, T)`가 토큰×토큰 점수표입니다.

## 실습 10-3. 코사인 유사도 (NumPy)

목표: 정규화 후 내적이 코사인이 됨을 확인합니다.

```python
# lecture10_cosine.py
import numpy as np

def cosine(a, b):
    a = np.asarray(a, dtype=float)
    b = np.asarray(b, dtype=float)
    return (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))

print(cosine([3, 0], [1, 1]))  # ≈ 0.7071
```

`np.linalg.norm`은 유클리드 길이입니다.

## LLM에서는 어디에 사용될까?

토큰은 Embedding Matrix `(V, d)`에서 행을 읽어 벡터가 됩니다.

그 다음 Q/K/V Linear, Attention 점수 $QK^\top$, MLP, LM Head가 모두 내적·행렬곱입니다.

| 위치 | 연산 | Shape 감각 |
|---|---|---|
| Embedding | 인덱싱 | `(V, d)` → `(T, d)` |
| Q/K/V | Linear | `(T, d) @ (d, d_k)` |
| 점수 | $QK^\top$ | `(T, d_k)@(d_k, T)→(T, T)` |
| LM Head | Linear | `(d,) → (V,)` |

> 📘 **심화**
>
> 37강 Dot-Product Attention에서 $QK^\top/\sqrt{d_k}$와 Softmax를 이어서 다룹니다.

## 자주 하는 실수

1. `*`와 `@` 혼동 — 점수는 `@`.
2. Shape 무시 — 가운데 차원이 같아야 함.
3. $AB=BA$로 착각.
4. bias 길이와 `d_out` 불일치.
5. 배치 `(B,T,d)`를 잊고 2D만 외움.

## 핵심 요약

- 내적은 대응 성분 곱의 합(Scalar)이다.
- 코사인 유사도는 길이 1로 맞춘 뒤의 내적이다.
- 행렬곱 한 칸 = 행·열 내적. Shape `(m,n)@(n,p)→(m,p)`.
- 일반적으로 $AB\neq BA$.
- Linear는 $xW+b$ (또는 $Wx+b$)로 재표현한다.
- Attention 점수 $QK^\top$와 LM Head도 같은 행렬곱이다.

## 용어 사전

| 용어 | 설명 |
|---|---|
| Dot Product | 대응 성분 곱의 합, Scalar |
| Norm $\|\cdot\|$ | 벡터 길이 |
| Cosine Similarity | 정규화 후 내적 |
| Matrix Multiplication | 행·열 내적으로 새 행렬 |
| Hadamard Product | 요소별 곱 $\odot$ |
| Transpose | 행↔열 |
| Linear Layer | $y=xW+b$ 형태 |
| Weight / Bias | 학습 가중치 · 편향 |
| Shape | 텐서 차원 구조 |
| `@` | 행렬곱/내적 연산자 |
| $QK^\top$ | Attention 점수(스케일 전) |
| Embedding | 토큰→벡터 |
| Orthogonal | 내적 0 |
| Batch | 여러 샘플을 묶은 축 $B$ |

## 연습문제

### 기초

행렬곱 가능한 쌍은?

1. `(3,4)@(4,2)`
2. `(3,4)@(3,2)`
3. `(2,3,4)@(4,5)`

코사인 유사도가 1에 가깝다는 것은 기하적으로 무엇을 뜻합니까?

### 계산

$[1,2]\cdot[2,3]$을 구하시오.

$$
\begin{bmatrix}1&2\\0&1\end{bmatrix}
\begin{bmatrix}3&0\\1&2\end{bmatrix}
$$

을 손계산하시오.

$A=\begin{bmatrix}1&0\\1&1\end{bmatrix}$, $B=\begin{bmatrix}0&1\\1&0\end{bmatrix}$일 때 $AB$와 $BA$를 구하시오.

### 코드

다음 출력은?

```python
import numpy as np
X = np.array([[1, 2], [3, 4]])
W = np.array([[1, 0], [0, 1]])
print(X @ W)
print(X * W)
```

### 응용

LM Head가 `(d,V)` 곱일 때, $\mathbf{h}\in\mathbb{R}^{d}$의 logits Shape와 의미를 설명하시오.

왜 $Q$와 $K$의 내적이 “관련 점수”가 될 수 있는지 두 문장으로 쓰시오.

$B=4$, $T=128$, $d=768$일 때 Q projection `(d,d)` 출력 Shape는?

---

## 정답 및 해설

### 기초

1과 3. 1→`(3,2)`. 3→`(2,3,5)`. 2는 가운데 불일치.

코사인 ≈1 → 두 벡터 방향이 거의 같음.

### 계산

$8$.

$\begin{bmatrix}5&4\\1&2\end{bmatrix}$.

$AB=\begin{bmatrix}0&1\\1&1\end{bmatrix}$, $BA=\begin{bmatrix}1&1\\1&0\end{bmatrix}$ (서로 다름).

### 코드

`X @ W` → `X` 그대로. `X * W` → `[[1,0],[0,4]]`.

### 응용

logits `(V,)` (또는 `(B,T,V)`). 각 성분은 다음 토큰 후보 점수.

비슷한 방향의 쿼리·키는 내적이 커져 더 많이 참조됩니다.

출력 Shape `(4, 128, 768)`.
