# 7강. 파일 입출력과 데이터 다루기
## 이번 강에서 배우는 내용

- open으로 텍스트 파일을 읽고 쓴다
- with 문으로 파일을 안전하게 닫는다
- JSON, CSV 형식을 읽고 쓴다
- pathlib.Path로 경로를 다룬다
- 작은 말뭉치 파일을 읽어 토큰 ID로 변환하는 파이프라인을 만든다

## 왜 중요한가?
LLM은 데이터가 없으면 학습할 수 없다.

실제 파이프라인은 대략 이렇게 시작한다.

```text
디스크의 텍스트/JSON/CSV
  → 읽기
    → 정제
      → 토큰화
        → ID 시퀀스
          → 배치
            → 모델 학습
```

아직 모델은 만들지 않지만, “파일을 열어 줄 단위로 읽고 구조화한다”는 기술은 Pretraining 데이터 준비·SFT 데이터셋·평가 로그 저장까지 계속 쓰인다.

실험 재현성 측면에서도, 설정(JSON)과 메트릭(CSV/JSONL)을 파일로 남기는 습관이 중요하다.

## 선수 개념
### 2.1 File I/O

**File I/O(파일 입출력)**는 프로그램이 디스크의 파일을 읽거나 쓰는 작업이다.

메모리는 프로그램을 끄면 사라질 수 있다. 파일은 그 결과를 **남겨 두는 저장소**이다.

### 2.2 텍스트와 바이너리

초보 단계에서 다루는 대부분은 **텍스트 파일**이다. (`.txt`, `.csv`, `.json`)

나중에 모델 가중치는 바이너리로 저장되지만, 7강의 범위는 텍스트·구조화 텍스트에 둔다.

### 2.3 Encoding

**Encoding(인코딩)**은 문자를 바이트로 표현하는 규칙이다. 한국어·이모지를 다루려면 보통 **UTF-8**을 명시한다.

```python
open("data.txt", "r", encoding="utf-8")
```

## 핵심 개념
### 3.1 파일 쓰기와 읽기

쓰기:

```python
# write_demo.py
# 목적: 텍스트 파일을 생성한다.

from pathlib import Path

def main() -> None:
    path = Path("corpus.txt")
    # "w": 쓰기 모드 (기존 내용 덮어씀)
    with path.open("w", encoding="utf-8") as f:
        f.write("오늘 날씨가 좋다\n")
        f.write("오늘 기분이 좋다\n")
    print("wrote", path)

if __name__ == "__main__":
    main()
```

읽기:

```python
# read_demo.py
from pathlib import Path

def main() -> None:
    path = Path("corpus.txt")
    with path.open("r", encoding="utf-8") as f:
        text = f.read()
    print(text)

if __name__ == "__main__":
    main()
```

### 3.2 with 문

**with**는 컨텍스트가 끝날 때 파일을 자동으로 닫아 준다.

```python
with open("corpus.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
# 이 지점에서 파일이 닫힌다
```

`close()`를 잊으면 파일 핸들이 남는 문제가 생길 수 있다. 습관적으로 `with`를 쓴다.

### 3.3 모드 요약

| 모드 | 의미 |
|---|---|
| `"r"` | 읽기 |
| `"w"` | 쓰기(덮어쓰기) |
| `"a"` | 이어 쓰기(append) |
| `"x"` | 새 파일 전용 생성(이미 있으면 에러) |

텍스트가 기본이다. 바이너리는 `"rb"`, `"wb"`처럼 `b`를 붙인다.

### 3.4 줄 단위 처리

큰 파일은 `read()`로 한 번에 다 읽지 않는 편이 안전하다. 줄 단위로 순회한다.

```python
from pathlib import Path

def iter_nonempty_lines(path: Path):
    with path.open("r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                yield line
```

`yield`는 **Generator(제너레이터)**를 만드는 문법이다.  
지금은 “한 줄씩 흘려보낸다” 정도로 이해하면 충분하다. 대용량 말뭉치에서 메모리를 아끼는 기본 패턴이다.

### 3.5 JSON

**JSON(JavaScript Object Notation)**은 딕셔너리·리스트와 잘 맞는 텍스트 데이터 형식이다. 설정 파일과 API 응답에 흔하다.

```python
# json_demo.py
import json
from pathlib import Path

def main() -> None:
    config = {
        "model": "toy-gpt",
        "lr": 3e-4,
        "batch_size": 4,
        "special_tokens": ["<pad>", "<unk>"],
    }
    path = Path("config.json")
    path.write_text(json.dumps(config, ensure_ascii=False, indent=2), encoding="utf-8")

    loaded = json.loads(path.read_text(encoding="utf-8"))
    print(loaded["lr"])

if __name__ == "__main__":
    main()
```

- `json.dumps`: Python 객체 → JSON 문자열
- `json.loads`: JSON 문자열 → Python 객체
- `ensure_ascii=False`: 한글을 `\uXXXX`로 이스케이프하지 않음
- `indent=2`: 사람이 읽기 쉬운 들여쓰기

**JSONL(JSON Lines)**는 한 줄에 JSON 객체 하나인 형식이다. 대용량 데이터셋에 자주 쓰인다.

```text
{"prompt": "안녕", "response": "안녕하세요"}
{"prompt": "날씨?", "response": "맑습니다"}
```

```python
import json
from pathlib import Path

def load_jsonl(path: Path) -> list[dict]:
    rows = []
    with path.open("r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                rows.append(json.loads(line))
    return rows
```

SFT 데이터셋이 이런 형태인 경우가 많다.

### 3.6 CSV

**CSV(Comma-Separated Values)**는 표 형식 텍스트이다. 실험 로그·메트릭 저장에 자주 쓴다.

```python
# csv_demo.py
import csv
from pathlib import Path

def main() -> None:
    path = Path("metrics.csv")
    rows = [
        {"step": 100, "loss": 2.5},
        {"step": 200, "loss": 1.8},
    ]

    with path.open("w", encoding="utf-8", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=["step", "loss"])
        writer.writeheader()
        writer.writerows(rows)

    with path.open("r", encoding="utf-8", newline="") as f:
        reader = csv.DictReader(f)
        for row in reader:
            # CSV는 문자열로 읽히므로 필요 시 변환
            print(int(row["step"]), float(row["loss"]))

if __name__ == "__main__":
    main()
```

주의: CSV에서 읽은 값은 기본적으로 **문자열**이다. 숫자 계산 전에 `int`/`float` 변환이 필요하다.

### 3.7 pathlib

**pathlib.Path**는 파일 경로를 객체로 다루는 표준 라이브러리이다.

```python
from pathlib import Path

data_dir = Path("data")
data_dir.mkdir(exist_ok=True)
file_path = data_dir / "corpus.txt"  # 운영체제에 맞게 경로 결합
print(file_path.name)     # corpus.txt
print(file_path.suffix)   # .txt
print(file_path.exists())
```

문자열로 `"data" + "/" + "corpus.txt"`를 직접 이어 붙이는 것보다 안전하고 읽기 쉽다.

## 직관적으로 이해하기
파일을 창고, 프로그램을 작업대로 비유하자.

| 작업 | 비유 |
|---|---|
| write | 창고에 상자 보관 |
| read | 창고에서 상자 꺼내기 |
| JSON | 라벨이 잘 붙은 정리된 상자 |
| CSV | 표가 그려진 대장 |
| JSONL | 한 줄에 상자 하나, 컨베이어 벨트 |
| pathlib | 창고 주소 체계 |

LLM 학습은 “창고에서 원문을 꺼내 가공해 모델에 공급”하는 물류에 가깝다.

## 작은 숫자·데이터 예제
`corpus.txt`:

```text
오늘 날씨가 좋다
오늘 기분이 좋다
내일 날씨가 맑다
```

목표:

1. 파일을 줄 단위로 읽는다
2. 6강 방식의 vocab을 만든다
3. 각 줄을 ID 리스트로 인코딩해 `encoded.jsonl`로 저장한다

첫 줄 `"오늘 날씨가 좋다"`가 `[2, 3, 4]`가 된다고 가정하면(특수 토큰 예약 후), 파일로 남기는 결과는 대략:

```text
{"text": "오늘 날씨가 좋다", "ids": [2, 3, 4]}
```

이 한 줄이 “원시 텍스트 → 학습 가능한 숫자 시퀀스”의 기록이다.

## 코드로 파이프라인 만들기
```python
# prepare_corpus.py
# 목적: 텍스트 파일을 읽어 vocab/인코딩 결과를 저장한다.

from __future__ import annotations

import json
from pathlib import Path

def read_lines(path: Path) -> list[str]:
    lines: list[str] = []
    with path.open("r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                lines.append(line)
    return lines

def build_vocab(lines: list[str]) -> dict[str, int]:
    vocab = {"<pad>": 0, "<unk>": 1}
    for line in lines:
        for tok in line.split():
            if tok not in vocab:
                vocab[tok] = len(vocab)
    return vocab

def encode(text: str, vocab: dict[str, int]) -> list[int]:
    unk = vocab["<unk>"]
    return [vocab.get(t, unk) for t in text.split()]

def main() -> None:
    data_dir = Path("data")
    data_dir.mkdir(exist_ok=True)

    corpus_path = data_dir / "corpus.txt"
    if not corpus_path.exists():
        corpus_path.write_text(
            "오늘 날씨가 좋다\n오늘 기분이 좋다\n내일 날씨가 맑다\n",
            encoding="utf-8",
        )

    lines = read_lines(corpus_path)
    vocab = build_vocab(lines)

    (data_dir / "vocab.json").write_text(
        json.dumps(vocab, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )

    out_path = data_dir / "encoded.jsonl"
    with out_path.open("w", encoding="utf-8") as f:
        for line in lines:
            row = {"text": line, "ids": encode(line, vocab)}
            f.write(json.dumps(row, ensure_ascii=False) + "\n")

    print(f"lines={len(lines)}, vocab_size={len(vocab)}")
    print(f"wrote {out_path}")

if __name__ == "__main__":
    main()
```

이 스크립트가 하는 일:

```text
corpus.txt → vocab.json + encoded.jsonl
```

이후 강의에서 `encoded.jsonl`의 `ids`를 텐서로 바꾸면 학습 입력이 된다.

## LLM에서는 어디에 사용될까?
| 형식 | LLM 워크플로에서의 예 |
|---|---|
| `.txt` / `.jsonl` | Pretraining 말뭉치, 문서 스트림 |
| JSON | 학습 설정, Tokenizer 설정, 모델 config |
| JSONL | SFT(instruction-response) 데이터 |
| CSV | step별 loss, 평가 점수 로그 |
| pathlib | 체크포인트 디렉터리, 데이터셋 경로 관리 |

대규모 데이터는 한 번에 RAM에 올리지 않는다.

```text
파일 스트림 → 미니배치 → GPU
```

7강에서 줄 단위 읽기·JSONL을 익히는 이유는, 나중에 `Dataset`/`DataLoader`를 만날 때 “데이터가 원래 어디에 있었는가”를 이해하기 위해서다.

체크포인트도 결국 파일이다.

```text
model.pt / model.safetensors
optimizer 상태
trainer_state.json
```

지금은 텍스트만 다루지만, “상태를 파일로 남긴다”는 사고방식은 동일하다.

## 실습
### 실습 1 — 일기 파일

`notes.txt`에 세 줄을 쓰고, 다시 읽어 줄 수를 출력한다.

### 실습 2 — 설정 JSON

`train_config.json`에 `lr`, `epochs`, `model_name`을 저장하고 읽어 출력한다.

### 실습 3 — 메트릭 CSV

step=1..5, loss가 `3.0, 2.5, 2.1, 1.8, 1.6`인 CSV를 만든 뒤, 평균 loss를 계산한다.

### 실습 4 — JSONL 변환

실습 1의 각 줄을 `{"text": ...}` JSONL로 저장한다.

## 자주 하는 실수
1. **인코딩을 생략해 한글이 깨진다**  
   `encoding="utf-8"`을 명시한다.

2. **`with` 없이 열고 닫기를 잊는다**  
   특히 예외가 나면 파일이 열린 채로 남을 수 있다.

3. **`"w"`로 열어 기존 데이터를 날린다**  
   이어 쓰려면 `"a"`, 새 파일만 만들려면 `"x"`를 검토한다.

4. **CSV 숫자를 문자열 그대로 평균 낸다**  
   반드시 `float` 변환 후 계산한다.

5. **경로를 문자열로 난잡하게 이어 붙인다**  
   `Path("a") / "b" / "c.txt"`를 사용한다.

6. **큰 파일을 `read()`로 한 번에 읽는다**  
   말뭉치가 커지면 메모리 부족이 난다. 줄/청크 단위로 처리한다.

## 핵심 요약
- 파일 입출력은 데이터를 프로그램 밖으로 저장·재유입하는 기술이다
- `with` + `encoding="utf-8"`이 텍스트 처리의 기본이다
- JSON/JSONL은 중첩 구조·샘플 스트림에, CSV는 표형 로그에 적합하다
- pathlib로 경로를 안전하게 다룬다
- “텍스트 파일 → vocab/ids 파일” 파이프라인이 LLM 데이터 준비의 축소판이다

## 용어 사전
| 용어 | 의미 |
|---|---|
| File I/O | 파일 읽기/쓰기 |
| Encoding / UTF-8 | 문자를 바이트로 표현하는 규칙 |
| with | 리소스를 안전하게 여닫는 문법 |
| JSON | 딕셔너리·리스트형 텍스트 데이터 형식 |
| JSONL | 한 줄 하나의 JSON 객체 |
| CSV | 쉼표(또는 구분자)로 구분된 표 형식 |
| pathlib.Path | 객체형 경로 다루기 |
| Generator (`yield`) | 값을 한 번에 하나씩 생산하는 방식 |

SFT는 보통 (지시, 응답)처럼 필드가 있는 샘플 단위가 필요하다. JSONL은 샘플마다 구조를 보존하기 쉽다. Pretraining은 대량 원문을 흘려보내면 되어 순수 텍스트 스트림도 흔하다.
