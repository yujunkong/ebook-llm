# 3강. 변수, 자료형, 연산
## 이번 강에서 배우는 내용

- 변수(variable)에 값을 담고 이름을 붙인다
- int, float, str, bool의 차이를 설명한다
- 산술·비교·논리 연산을 사용한다
- 형 변환(type conversion)으로 자료형을 바꾼다
- f-string으로 문자열을 조립한다
- 작은 숫자 예제로 “점수 → 출력 문장”을 만든다

## 왜 중요한가?
LLM 코드는 결국 숫자를 넣고 숫자를 바꾼다.

- Token ID는 정수이다
- 확률과 Loss는 실수이다
- 로그 메시지는 문자열이다
- “학습 중인가?” 같은 상태는 불리언이다

자료형과 연산을 헷갈리면, 나중에 Softmax나 Cross-Entropy를 구현할 때 “왜 이 값이 이상한가”를 추적하기 어렵다.

이번 강의의 목표는 화려한 문법이 아니라, **값을 정확히 담는 습관**이다.

## 선수 개념
### 2.1 변수 (Variable)

**Variable(변수)**는 값에 붙이는 이름이다.

```python
learning_rate = 0.001
```

여기서 `learning_rate`는 이름, `0.001`은 값이다.

왜 필요한가?

- 같은 숫자를 여러 곳에 하드코딩하면 수정이 힘들다
- 이름이 의미를 설명한다 (`0.001`보다 `learning_rate`가 읽기 쉽다)

Python에서 변수는 “상자”에 가깝게 생각해도 초보 단계에서는 충분하다.  
(정확히는 이름표가 객체를 가리키는 것에 가깝지만, 세부 의미는 이후 강의에서 자연스럽게 드러난다.)

### 2.2 자료형 (Data Type)

**Data Type(자료형)**은 값이 어떤 종류의 데이터인지, 어떤 연산이 가능한지를 규정한다.

같은 `+`라도 자료형에 따라 의미가 달라진다.

```python
1 + 2          # 숫자 덧셈 → 3
"1" + "2"      # 문자열 연결 → "12"
```

## 핵심 개념
### 3.1 int — 정수

**int(integer, 정수)**는 소수점이 없는 숫자이다.

```python
vocab_size = 32000
num_layers = 12
batch_size = 4
```

LLM에서 자주 보는 정수:

- 토큰 ID: `101`, `2023`
- 시퀀스 길이: `512`
- 에폭 수: `3`

### 3.2 float — 실수

**float(floating-point number, 부동소수점 실수)**는 소수점이 있는 숫자이다.

```python
temperature = 0.7
learning_rate = 3e-4   # 0.0003
loss = 2.345
```

`3e-4`는 과학적 표기법으로 $3 \times 10^{-4}$이다. 학습률 표기에 자주 쓴다.

주의: 컴퓨터의 float는 십진수를 완벽히 표현하지 못하는 경우가 있다.

```python
print(0.1 + 0.2)  # 0.30000000000000004 같은 결과가 나올 수 있다
```

지금은 “실수 연산은 오차가 있을 수 있다”만 기억하면 된다. 수치 안정성은 이후 Loss·Softmax에서 다시 만난다.

### 3.3 str — 문자열

**str(string, 문자열)**는 텍스트이다. 따옴표로 감싼다.

```python
prompt = "오늘 날씨가"
model_name = 'gpt-small'
```

작은따옴표와 큰따옴표는 기본적으로 같다. 문자열 안에 따옴표가 들어가면 서로 섞어 쓴다.

```python
msg = "그는 '다음 토큰'을 예측한다"
```

여러 줄 문자열은 삼중 따옴표를 쓴다.

```python
docs = """
첫 줄
둘째 줄
"""
```

### 3.4 bool — 참/거짓

**bool(boolean, 불리언)**은 `True` 또는 `False` 두 값만 갖는다.

```python
is_training = True
use_cuda = False
```

조건문, 조기 종료, 체크포인트 저장 여부 등 “켜짐/꺼짐”을 표현할 때 쓴다.

### 3.5 type()으로 확인하기

**type()**은 값의 자료형을 알려 주는 내장 함수이다.

```python
print(type(32000))      # <class 'int'>
print(type(0.7))        # <class 'float'>
print(type("hello"))    # <class 'str'>
print(type(True))       # <class 'bool'>
```

에러가 나면 먼저 `type`을 찍어 보는 습관이 디버깅의 기본이다.

### 3.6 산술 연산

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---:|
| `+` | 더하기 | `3 + 2` | 5 |
| `-` | 빼기 | `3 - 2` | 1 |
| `*` | 곱하기 | `3 * 2` | 6 |
| `/` | 나누기(항상 float) | `5 / 2` | 2.5 |
| `//` | 몫(정수 나눗셈) | `5 // 2` | 2 |
| `%` | 나머지 | `5 % 2` | 1 |
| `**` | 거듭제곱 | `2 ** 3` | 8 |

LLM 맥락 예:

```python
tokens_per_batch = batch_size * seq_len
total_tokens = tokens_per_batch * num_steps
```

수식으로 쓰면, 배치 하나에서 보는 토큰 수는

$$
N_{\text{batch}} = B \times T
$$

이고, $S$ 스텝을 돌리면 누적 토큰 수는

$$
N_{\text{total}} = \sum_{s=1}^{S} (B \times T) = S \cdot B \cdot T
$$

입니다. 파이썬의 `*` 연산이 바로 이 곱을 계산합니다. `**`는 거듭제곱 $a^{b}$에 해당합니다.

$$
2^{3} = 8,\qquad
10^{-3} = 0.001
$$

몫·나머지는 정수를 “칸”으로 나눌 때 자주 등장합니다. 예를 들어 토큰 위치 $i$를 블록 크기 $k$로 나누면

$$
\text{block} = \left\lfloor \frac{i}{k} \right\rfloor,\qquad
\text{offset} = i \bmod k
$$

이고, 파이썬에서는 `i // k`, `i % k`로 씁니다.

### 3.7 비교 연산과 논리 연산

비교 연산은 `bool`을 만든다.

```python
print(3 > 2)     # True
print(3 == 2)    # False
print(3 != 2)    # True
print(0.7 <= 1)  # True
```

논리 연산:

```python
print(True and False)  # False
print(True or False)   # True
print(not True)        # False
```

예:

```python
ready = (batch_size > 0) and (seq_len > 0)
```

논리 연산을 진리표로 보면 다음과 같습니다.

| $A$ | $B$ | $A \land B$ (`and`) | $A \lor B$ (`or`) |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

$\lnot A$ (`not A`)는 참↔거짓을 뒤집습니다. 학습 코드에서는 “배치가 비어 있지 않고, CUDA를 쓸 수 있을 때만 학습”처럼 **여러 조건을 동시에** 검사할 때 씁니다.

### 3.8 형 변환 (Type Conversion)

**Type Conversion(형 변환)**은 값의 자료형을 바꾸는 것이다.

```python
n = int("42")       # 문자열 → 정수
x = float("3.14")   # 문자열 → 실수
s = str(42)         # 정수 → 문자열
flag = bool(1)      # 1 → True, 0 → False
```

자주 하는 실수:

```python
# "3" + 1  # TypeError
print(int("3") + 1)  # 4
```

사용자 입력(`input`)은 기본적으로 문자열이다. 숫자 계산 전에 변환이 필요하다.

### 3.9 f-string

**f-string**은 문자열 안에 표현식을 삽입하는 문법이다. 문자열 앞에 `f`를 붙인다.

```python
epoch = 3
loss = 1.2345
print(f"epoch={epoch}, loss={loss:.4f}")
```

출력:

```text
epoch=3, loss=1.2345
```

`:.4f`는 소수점 아래 4자리로 포맷한다는 뜻이다. 학습 로그를 찍을 때 매우 자주 쓴다.

### 3.10 연산 우선순위와 괄호

산술의 기본 우선순위는 일상 수학과 같습니다.

$$
a + b \times c = a + (b \cdot c)
$$

의심스러우면 괄호를 씁니다. 학습률 스케줄처럼 식이 길어질수록 괄호가 버그를 줄입니다.

```python
# 의도가 "먼저 나누고 더하기"라면 괄호로 고정
warmup = step / warmup_steps
lr = base_lr * (warmup + 1.0)   # 예시용 단순식
```

### 3.11 bool과 숫자 0/1

조건식 밖에서 `bool`은 종종 0/1처럼 취급됩니다.

$$
\mathbf{1}_{\text{조건}} =
\begin{cases}
1 & \text{조건이 참}\\
0 & \text{조건이 거짓}
\end{cases}
$$

```python
confident = gap >= 1.0
print(int(confident))  # True → 1, False → 0
```

나중에 마스크(padding mask)를 만들 때 “참인 위치만 1”이라는 감각이 그대로 이어집니다.

## 직관적으로 이해하기
자료형은 “그릇의 모양”이다.

| 자료형 | 그릇 비유 | LLM에서의 예 |
|---|---|---|
| int | 개수 세기용 접시 | token id, layer 수 |
| float | 눈금이 있는 비커 | loss, probability |
| str | 라벨 스티커 | prompt, 파일 경로 |
| bool | 스위치 | training mode on/off |

연산을 잘못 고르면 그릇에 맞지 않는 재료를 넣는 것과 같다.  
`"0.7" * 2`는 숫자가 아니라 문자열 반복 `"0.70.7"`이 된다.

## 작은 숫자 예제 — 토큰 점수 로그 만들기
모델이 세 토큰에 점수를 줬다고 가정한다. (아직 Softmax는 쓰지 않는다.)

| 토큰 | 점수 |
|---|---:|
| 좋다 | 2.0 |
| 맑다 | 1.0 |
| 의자 | 0.0 |

가장 높은 점수와 그 토큰 이름을 변수로 담아 출력해 보자.

```python
# score_log.py
# 목적: 자료형과 f-string으로 간단한 로그를 만든다.

best_token = "좋다"
best_score = 2.0
second_score = 1.0

gap = best_score - second_score
confident = gap >= 1.0

print(f"선택 토큰: {best_token}")
print(f"점수: {best_score:.1f}")
print(f"2등과 차이: {gap:.1f}")
print(f"충분히 확실한가?: {confident}")
```

실행 결과:

```text
선택 토큰: 좋다
점수: 2.0
2등과 차이: 1.0
충분히 확실한가?: True
```

이 예제의 요점:

- 토큰 이름은 `str`
- 점수는 `float`
- 차이의 충분 여부는 `bool`
- 로그 문장은 f-string

### 미니 예제 보강 — 점수 차이를 수식으로

세 점수 $s_1=2.0,\ s_2=1.0,\ s_3=0.0$에 대해 최댓값과 2등의 차이는

$$
\Delta = s_{(1)} - s_{(2)} = 2.0 - 1.0 = 1.0
$$

입니다. “충분히 확실하다”는 판정은 임계값 $\tau=1.0$과 비교합니다.

$$
\text{confident} = [\Delta \ge \tau] = \mathrm{True}
$$

아직은 Softmax 확률이 아닙니다. 다만 **숫자를 변수에 담고, 빼고, 비교하고, 문장으로 출력한다**는 파이프라인은 이미 LLM 로그와 같습니다.

### 미니 예제 — 학습률 표기와 float

학습률 $3 \times 10^{-4}$를 코드와 수식으로 대응시킵니다.

$$
\eta = 3 \times 10^{-4} = 0.0003
$$

```python
lr = 3e-4
print(lr)                 # 0.0003
print(f"lr={lr:.6f}")     # lr=0.000300
print(type(lr))           # <class 'float'>
```

`3e-4`는 “사람이 읽기 쉬운 표기”이고, 메모리 안에서는 동일한 float 값입니다. 로그를 남길 때는 `:.6f`처럼 **자릿수를 고정**해 두면 실험 비교가 쉽습니다.

### 미니 예제 — 정수 나눗셈으로 스텝 구간 나누기

전체 스텝 $S=1000$, 로그 주기 $k=100$일 때, 스텝 $t$가 속한 구간 번호는

$$
q(t) = \left\lfloor \frac{t}{k} \right\rfloor
$$

입니다.

```python
S, k = 1000, 100
for t in (0, 99, 100, 250, 999):
    print(t, t // k)
```

출력 요지: `0→0`, `99→0`, `100→1`, `250→2`, `999→9`.  
“100스텝마다 한 번” 같은 주기는 결국 `t % k == 0` 또는 `t // k`의 변화로 표현됩니다.

## 코드로 정리하기
```python
# types_ops_demo.py
# 목적: int/float/str/bool과 연산을 한곳에서 확인한다.

def main() -> None:
    vocab_size = 32000
    learning_rate = 3e-4
    model_name = "toy-gpt"
    is_training = True

    print(type(vocab_size), vocab_size)
    print(type(learning_rate), learning_rate)
    print(type(model_name), model_name)
    print(type(is_training), is_training)

    # 산술
    batch_size = 4
    seq_len = 128
    tokens = batch_size * seq_len
    print(f"tokens per batch = {tokens}")

    # 형 변환
    raw = "0.75"
    temperature = float(raw)
    print(f"temperature = {temperature} ({type(temperature)})")

    # 비교 / 논리
    ok = (tokens > 0) and (temperature > 0)
    print(f"config ok? {ok}")

if __name__ == "__main__":
    main()
```

## 수식 보강 — 변수와 식

변수는 값에 이름을 붙인 것이고, 연산은 함수로 볼 수 있습니다.

$$
y = ax + b
$$

정수 나눗셈·나머지:

$$
n = qd + r,\quad 0\le r < |d|
$$

토큰 ID도 결국 정수 변수입니다. 이후 Embedding은 이 정수를 벡터로 바꿉니다.

## LLM에서는 어디에 사용될까?
| 개념 | LLM에서의 위치 |
|---|---|
| int | Token ID, vocabulary size, step, epoch |
| float | logits, probabilities, loss, learning rate |
| str | prompt, special token 이름, 체크포인트 경로 |
| bool | `model.train()` / `model.eval()` 모드 플래그 |
| f-string | 학습 로그, 실험 이름, 메트릭 출력 |

예: 학습 루프 로그는 대략 이런 형태가 된다.

```text
epoch=1 step=100 loss=2.3417 lr=0.000300
```

이 한 줄을 만들려면 이미 이번 강의의 재료가 전부 필요하다.

### 수식으로 보는 로그 한 줄

로그에 찍는 값들을 기호로 두면

$$
\text{epoch}=e,\quad
\text{step}=t,\quad
L_t=\text{loss},\quad
\eta_t=\text{learning rate}
$$

이고, f-string은 이 기호들을 사람이 읽는 문자열로 직렬화하는 장치입니다. 모델 수식 자체는 아니지만, **실험 재현**에 필수인 “숫자 ↔ 기록” 다리입니다.

### 자료형별 연산 복잡도 감각 (초보용)

초보 단계에서는 다음 정도만 기억하면 충분합니다.

| 연산 | 대략적 비용 | 비고 |
|---|---|---|
| int/float 산술 한 번 | $O(1)$ | 상수 시간 |
| 길이 $n$ 문자열 연결을 반복 | 최악의 경우 $O(n^2)$에 가까워질 수 있음 | 리스트에 모은 뒤 `join` |
| `type(x)` | $O(1)$ | 디버깅용 |

지금은 “큰 문자열을 `+=`로 수만 번 이어 붙이지 말자” 정도의 경고로 충분합니다. 토큰 시퀀스는 보통 **리스트에 append**한 뒤 한꺼번에 처리합니다.

## 자주 하는 실수
1. **문자열과 숫자를 바로 더한다**  
   `"3" + 1`은 에러다. `int("3") + 1` 또는 `"3" + str(1)`처럼 의도를 분명히 한다.

2. **`/`와 `//`를 혼동한다**  
   `5 / 2`는 `2.5`, `5 // 2`는 `2`이다. 인덱스 계산에서는 `//`가 필요할 때가 많다.

3. **변수 이름을 의미 없이 짓는다**  
   `a`, `b`, `x1`만 쓰면 며칠 뒤 자신조차 못 읽는다. `loss`, `lr`, `batch_size`처럼 짓는다.

4. **bool을 문자열 `"True"`와 혼동한다**  
   `"True"`는 str이다. 조건식에는 `True`/`False`를 쓴다.

5. **float 오차를 버그로만 생각한다**  
   `0.1 + 0.2`의 미세 오차는 정상 동작에 가깝다. 정확한 비교가 필요하면 허용 오차를 둔다.

## 수식 체크리스트 (3강)

이번 강에서 코드와 바로 대응시킨 식을 한곳에 모아 둡니다.

$$
N_{\text{batch}}=B\cdot T,\qquad
N_{\text{total}}=S\cdot B\cdot T
$$

$$
\left\lfloor i/k \right\rfloor = i\,//\,k,\qquad
i\bmod k = i\,\%\,k
$$

$$
\eta = 3\times 10^{-4} = \mathtt{3e-4}
$$

$$
\mathbf{1}_{\Delta\ge\tau}=\begin{cases}1&\Delta\ge\tau\\0&\text{otherwise}\end{cases}
$$

이 네 줄만 기억해도, 이후 학습 로그·스텝 주기·학습률 표기를 수식으로 읽을 수 있습니다.

## 핵심 요약
- 변수는 값에 이름을 붙인 것이다
- int/float/str/bool은 LLM 코드의 기본 재료이다
- 연산자는 자료형에 따라 의미가 달라진다
- 형 변환으로 계산 가능한 형태로 맞춘다
- f-string은 로그와 디버깅에 필수이다
- 배치 토큰 수 $N=B\cdot T$, 누적 $N_{\text{total}}=S\cdot B\cdot T$처럼 산술을 수식으로 대응시킬 수 있다
- `//`, `%`는 $\lfloor i/k\rfloor$, $i\bmod k$에 해당한다

## 용어 사전
| 용어 | 의미 |
|---|---|
| Variable | 값에 붙인 이름 |
| int | 정수 자료형 |
| float | 실수 자료형 |
| str | 문자열 자료형 |
| bool | 참/거짓 자료형 |
| Operator | 값을 결합·비교하는 기호 (`+`, `==` 등) |
| Type Conversion | 자료형을 바꾸는 과정 |
| f-string | `f"...{expr}..."` 형태의 문자열 포맷 |
| `type()` | 값의 자료형을 확인하는 함수 |
| Scientific notation | `3e-4`처럼 $a\times10^{b}$ 표기 |
| Indicator | 조건이 참이면 1, 거짓이면 0인 $[\cdot]$ 표기 |
