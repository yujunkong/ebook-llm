# 4강. 조건문과 반복문
## 이번 강에서 배우는 내용

- if / elif / else로 분기를 만든다
- for, while로 반복을 만든다
- range로 정수 수열을 생성한다
- break, continue로 반복을 중단하거나 건너뛴다
- 학습 루프·조기 종료를 작은 코드로 흉내 낸다

## 왜 중요한가?
LLM 학습 코드의 뼈대는 반복이다.

```text
for epoch in epochs:
    for batch in dataloader:
        예측 → loss 계산 → 역전파 → 파라미터 업데이트
        if step % 100 == 0:
            로그 출력
        if loss가 충분히 작으면:
            조기 종료
```

조건문과 반복문을 모르면, Transformer 수식을 알아도 **학습 코드를 읽거나 쓸 수 없다**.

이번 강의는 문법 자체보다, 나중에 만날 **훈련 루프의 미니어처**를 손에 익히는 데 초점을 둔다.

## 선수 개념
### 2.1 Control Flow

**Control Flow(제어 흐름)**는 코드가 어떤 순서로, 어떤 조건에서, 몇 번 실행되는지를 말한다.

기본은 위에서 아래로 한 줄씩이다.  
조건문·반복문은 그 직선 도로에 **갈림길**과 **원형 교차로**를 추가한다.

### 2.2 Indentation (들여쓰기)

Python은 **들여쓰기**로 코드 블록을 구분한다. 중괄호 `{}` 대신 공백(보통 4칸)을 쓴다.

```python
if True:
    print("이 줄은 if 블록")
print("이 줄은 if 밖")
```

들여쓰기가 어긋나면 `IndentationError`가 난다. 초반에 가장 흔한 문법 실수 중 하나이다.

## 핵심 개념
### 3.1 if / elif / else

**if**는 조건이 참일 때만 블록을 실행한다.

```python
loss = 2.5

if loss < 1.0:
    print("충분히 낮다")
elif loss < 2.0:
    print("중간")
else:
    print("아직 높다")
```

출력:

```text
아직 높다
```

- `if`: 첫 조건
- `elif`: 그다음 조건 (여러 개 가능)
- `else`: 앞 조건이 모두 거짓일 때

조건식은 보통 `bool`이 된다. `>`, `==`, `and`, `or`, `not`을 조합한다.

### 3.2 비교 시 주의

```python
x = 0.1 + 0.2
if x == 0.3:
    print("정확 일치")
else:
    print("미세 오차 가능")
```

float 비교는 `==`보다 허용 오차가 안전할 때가 많다.

```python
eps = 1e-9
if abs(x - 0.3) < eps:
    print("거의 같다")
```

### 3.3 for 반복

**for**는 시퀀스의 원소를 하나씩 꺼내 반복한다.

```python
tokens = ["오늘", "날씨가", "좋다"]
for t in tokens:
    print(t)
```

문자열도 글자 단위로 순회할 수 있다.

```python
for ch in "GPT":
    print(ch)
```

### 3.4 range

**range**는 정수 수열을 만든다. `for`와 함께 자주 쓴다.

```python
# 0, 1, 2
for i in range(3):
    print(i)

# 1, 2, 3, 4
for step in range(1, 5):
    print(step)

# 0, 2, 4
for i in range(0, 5, 2):
    print(i)
```

형태:

```text
range(stop)
range(start, stop)
range(start, stop, step)
```

`stop`은 포함되지 않는다. `range(3)` → 0, 1, 2.

수식으로 쓰면 `range(n)`은 정수 집합

$$
\{0, 1, 2, \ldots, n-1\}
$$

을, `range(a, b)`는

$$
\{a, a+1, \ldots, b-1\}
$$

을 생성합니다. `range(a, b, s)`는 공차 $s$인 등차수열입니다.

$$
a,\ a+s,\ a+2s,\ \ldots \quad (\text{값이 } b \text{ 미만인 동안})
$$

학습 스텝을 흉내 내면:

```python
num_steps = 5
for step in range(1, num_steps + 1):
    print(f"step={step}")
```

### 3.5 while 반복

**while**은 조건이 참인 동안 반복한다.

```python
loss = 3.0
step = 0

while loss > 1.0 and step < 10:
    # 아주 단순한 "학습" 흉내: 매 스텝 loss가 줄어든다고 가정
    loss = loss - 0.4
    step += 1
    print(f"step={step}, loss={loss:.1f}")
```

출력 예:

```text
step=1, loss=2.6
step=2, loss=2.2
step=3, loss=1.8
step=4, loss=1.4
step=5, loss=1.0
```

`while`은 종료 조건을 잘못 쓰면 **무한 루프**가 된다. 반드시 조건을 거짓으로 만드는 갱신이 있는지 확인한다.

### 3.6 break와 continue

**break**는 반복을 즉시 종료한다.  
**continue**는 이번 회차의 나머지를 건너뛰고 다음 회차로 간다.

```python
for step in range(1, 11):
    if step % 2 == 0:
        continue          # 짝수 스텝은 로그 생략
    if step >= 7:
        break             # 7 이상이면 중단
    print(f"log step={step}")
```

출력:

```text
log step=1
log step=3
log step=5
```

ML 비유:

- `continue`: 잘못된 배치를 건너뛰기
- `break`: early stopping으로 학습 종료

### 3.7 중첩 루프

루프 안에 루프를 둘 수 있다.

```python
num_epochs = 2
steps_per_epoch = 3

for epoch in range(1, num_epochs + 1):
    for step in range(1, steps_per_epoch + 1):
        print(f"epoch={epoch}, step={step}")
```

실제 학습도 “에폭 루프 × 배치 루프” 구조인 경우가 많다.

중첩 루프의 반복 횟수는 곱입니다. 에폭 $E$, 에폭당 배치 $M$이면 총 갱신 횟수는

$$
N_{\text{update}} = E \times M = \sum_{e=1}^{E} M
$$

입니다. 시간 복잡도를 대략 말하면, 배치 하나 처리 비용이 $C$일 때 전체는 $O(E\cdot M\cdot C)$ 스케일입니다. (실제 LLM에서는 시퀀스 길이·모델 크기까지 곱해집니다.)

### 3.8 누적 합과 for — $\sum$을 코드로

점수 리스트 $x_0, x_1, \ldots, x_{n-1}$의 합은

$$
S = \sum_{i=0}^{n-1} x_i
$$

이고, 파이썬으로는 다음과 같이 씁니다.

```python
xs = [2.0, 5.0, 1.0]
total = 0.0
for x in xs:
    total += x
print(total)  # 8.0
# 또는 sum(xs)
```

평균은

$$
\bar{x} = \frac{1}{n}\sum_{i=0}^{n-1} x_i
$$

입니다. 배치 Loss를 “여러 샘플 Loss의 평균”으로 정의하는 감각이 바로 이 식입니다.

### 3.9 조건문을 지시 함수로 보기

Early stopping 조건을 수식으로 쓰면

$$
\text{stop} = [L_t \le \tau] \lor [t \ge T_{\max}]
$$

입니다. 코드의 `if loss <= target or step >= max_steps`와 대응합니다.  
로그 주기 조건은

$$
\text{log} = [t \bmod k = 0]
$$

즉 `if step % k == 0`입니다.

## 직관적으로 이해하기
| 구문 | 직관 | LLM 비유 |
|---|---|---|
| if/elif/else | 갈림길 | loss가 크면 로그, 작으면 저장 |
| for | 목록을 순서대로 처리 | 배치를 하나씩 학습 |
| while | 목표에 닿을 때까지 반복 | loss가 기준 이하가 될 때까지 |
| break | 중간에 멈추기 | early stopping |
| continue | 이번 것만 건너뛰기 | 결측 배치 skip |
| range | 횟수 티켓 | step=1…N |

중요한 감각:

> 모델이 똑똑해지는 과정도, 코드 관점에서는 **같은 계산을 수많은 배치에 대해 반복**하는 일이다.

## 작은 숫자 예제 — 가짜 학습 루프
초기 loss가 4.0이고, 매 스텝 0.5씩 감소한다고 가정한다.  
loss가 1.0 이하이거나 step이 20을 넘으면 멈춘다.  
3의 배수 스텝에서만 로그를 남긴다.

손으로 추적:

| step | loss | 로그? | 종료? |
|---:|---:|---|---|
| 1 | 3.5 | X | X |
| 2 | 3.0 | X | X |
| 3 | 2.5 | O | X |
| 6 | 1.0 | O | O (loss≤1) |

코드:

```python
# toy_train_loop.py
# 목적: 조건문·반복문으로 학습 루프를 축소해 본다.

def main() -> None:
    loss = 4.0
    max_steps = 20
    target = 1.0

    for step in range(1, max_steps + 1):
        loss -= 0.5

        if step % 3 != 0:
            continue  # 로그 주기만 흉내

        print(f"step={step}, loss={loss:.1f}")

        if loss <= target:
            print("early stopping")
            break
    else:
        # for가 break 없이 끝난 경우에만 실행
        print("reached max_steps")

if __name__ == "__main__":
    main()
```

`for ... else`는 break 없이 정상 종료될 때 `else`가 실행된다. 알아 두면 디버깅에 도움이 된다.

### 손으로 추적 — 감소 수열

초기 $L_0=4.0$, 매 스텝 $L_t = L_{t-1}-0.5$이면

$$
L_t = 4.0 - 0.5\, t
$$

입니다. $L_t \le 1.0$이 되는 최소 $t$는

$$
4.0 - 0.5 t \le 1.0 \implies t \ge 6
$$

이므로 step 6에서 조기 종료가 맞습니다. 표를 그리기 전에 식으로 예측할 수 있으면, 코드 버그를 더 빨리 찾습니다.

### 미니 예제 — 합으로 평균 Loss 흉내

세 배치의 가짜 loss가 $2.0,\ 1.5,\ 1.0$일 때 에폭 평균은

$$
\bar{L} = \frac{1}{3}(2.0+1.5+1.0) = 1.5
$$

입니다.

```python
batch_losses = [2.0, 1.5, 1.0]
total = 0.0
for L in batch_losses:
    total += L
mean_loss = total / len(batch_losses)
print(mean_loss)  # 1.5
```

학습 로그의 `epoch loss`는 대개 이런 **합 → 나누기** 패턴입니다.

## 코드로 확장하기 — 토큰 생성 루프 스케치
1강에서 본 next-token 생성도 반복문이다.

```python
# generate_loop.py
# 목적: 생성 = "다음 토큰 선택"의 반복임을 코드로 고정한다.

def pick_next(last: str) -> str:
    table = {
        "오늘은": "날씨가",
        "날씨가": "좋다",
        "좋다": ".",
    }
    return table.get(last, "...")

def generate(prompt_tokens: list[str], max_new: int = 5) -> list[str]:
    tokens = list(prompt_tokens)
    for _ in range(max_new):
        nxt = pick_next(tokens[-1])
        tokens.append(nxt)
        if nxt == ".":
            break  # 문장 끝 토큰이면 중단
    return tokens

if __name__ == "__main__":
    result = generate(["오늘은"], max_new=5)
    print(" ".join(result))
```

출력 예:

```text
오늘은 날씨가 좋다 .
```

실제 GPT 생성은 `pick_next` 자리가 거대한 신경망으로 바뀐다.  
그러나 **바깥 루프의 모양**은 크게 다르지 않다.

## 수식 보강 — 조건·반복과 합

조건은 지시함수처럼 읽을 수 있습니다.

$$
\mathbf{1}[x>0]=\begin{cases}1&x>0\\0&\text{otherwise}\end{cases}
$$

길이 $n$ 리스트의 합은

$$
S=\sum_{i=1}^{n} x_i
$$

이며, `for` 루프가 이를 계산합니다. Softmax 분모 $\sum_j e^{z_j}$도 같은 패턴입니다.

## 배치 루프와 토큰 루프

```python
# 에폭 × 배치 — 학습 루프의 뼈대
data = list(range(20))
batch_size = 4
for epoch in range(2):
    for i in range(0, len(data), batch_size):
        batch = data[i:i + batch_size]
        # 여기서 loss.backward()가 들어간다
        assert len(batch) <= batch_size
print("done")
```

$$
\text{steps/epoch}=\left\lceil N/B\right\rceil
$$

조기 종료 조건 예:

$$
\text{stop if } L_{\mathrm{val}}^{(t)}>L_{\mathrm{val}}^{(t-k)}\ \text{for patience }k
$$

## LLM에서는 어디에 사용될까?
| 문법 | LLM 코드에서의 전형적 사용 |
|---|---|
| for epoch / for batch | Pretraining, SFT 학습 루프 |
| if step % N == 0 | 일정 간격 로깅, 평가, 체크포인트 |
| if loss.isnan() | 수치 불안정 감지 후 skip/중단 |
| while not done | 대화 에이전트, 도구 호출 루프 |
| break | early stopping, max length 도달 |
| continue | 빈 샘플·손상 샘플 건너뛰기 |

Inference(생성)에서도:

```text
while 아직 끝 토큰이 아니고 길이가 max_len 미만:
    다음 토큰 예측
    토큰 추가
```

조건·반복은 “모델 구조”만큼이나 “학습·생성 운영”의 핵심이다.

### 생성 길이를 수식으로

최대 새 토큰 수 $M$, 현재 길이 $\ell_0$에서 시작한다고 하면, 생성 루프는 대략

$$
\text{while }\ (\ell < \ell_0 + M)\ \land\ (\text{last} \neq \text{EOS})
$$

입니다. `for _ in range(M)` + `break` 조합이 이 논리를 구현하는 한 방법입니다.

복잡도 감각: 토큰을 하나 생성할 때마다 모델 forward 비용이 $C$라면, 최대 $M$토큰 생성은 $O(M\cdot C)$입니다. (실제 오토리그레시브 LLM에서는 길이가 늘어날수록 $C$ 자체도 커질 수 있습니다. 상세는 이후 권에서 다룹니다.)

`loss` 값에 따라 메시지를 출력한다.

- `loss < 1`: `good`
- `1 <= loss < 2`: `ok`
- 그 외: `high`

### 실습 3 — while로 목표 도달

`accuracy = 0.4`에서 시작해 매 스텝 `0.07`씩 증가시킨다.  
`accuracy >= 0.9` 또는 `step == 20`이 되면 멈추고, 최종 step과 accuracy를 출력한다.

`losses = [2.4, 2.1, 1.9, 1.7]`에 대해 for 루프로 $\sum$과 평균을 구하고, `sum`/`len` 결과와 같은지 확인한다.

`range(0, 20, 5)`가 만드는 수열을 수식 $0,5,10,15$와 대응시켜 손으로 쓰고, 코드로 확인한다.

## 자주 하는 실수
1. **들여쓰기를 탭/스페이스로 섞는다**  
   에디터에서 스페이스 4칸으로 통일한다.

2. **`=`와 `==`를 혼동한다**  
   `=`는 대입, `==`는 비교이다. `if loss = 1.0`은 문법 오류다.

3. **while 조건을 갱신하지 않는다**  
   무한 루프의 대표 원인이다. 루프 변수 변화를 눈으로 추적한다.

4. **range 끝값을 포함한다고 착각한다**  
   `range(1, 5)`는 1~4이다. `num_steps`번 돌리려면 `range(num_steps)` 또는 `range(1, num_steps+1)`을 의도적으로 고른다.

5. **break/continue 위치를 잘못 둔다**  
   로그를 찍기 전에 break하면 원인 파악이 어려워진다. 종료 직전 로그를 남기는 습관이 좋다.

## 핵심 요약
- if/elif/else는 조건에 따라 다른 코드를 실행한다
- for는 시퀀스·range를 순회하고, while은 조건이 참인 동안 반복한다
- break는 종료, continue는 이번 회차 건너뛰기이다
- 학습 루프와 생성 루프는 모두 조건·반복의 응용이다
- 들여쓰기가 Python 블록의 경계이다
- 합 $\sum_{i} x_i$, 평균 $\frac{1}{n}\sum_i x_i$는 for 누적으로 구현한다
- 중첩 루프 갱신 횟수는 $E\times M$ 스케일이다

| for | 시퀀스 순회 반복 |
| while | 조건 기반 반복 |
| range | 정수 수열 생성기 |

| Indentation | 블록을 구분하는 들여쓰기 |
| Early Stopping | 성능/손실 기준에 도달하면 학습을 일찍 끝내는 전략 |
