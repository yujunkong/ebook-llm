# 1권. Python · Tensor · 수학 · PyTorch

## 제4강. 조건문과 반복문

### 1. 이번 강의에서 배울 것

값을 담는 법을 배웠다. 이번 강의는 프로그램의 **흐름**을 제어한다.

이 강의를 마치면 다음을 할 수 있어야 한다.

- **if / elif / else**로 분기를 만든다
- **for**, **while**로 반복을 만든다
- **range**로 정수 수열을 생성한다
- **break**, **continue**로 반복을 중단하거나 건너뛴다
- 학습 루프·조기 종료를 작은 코드로 흉내 낸다

### 2. 왜 이것을 배우는가

LLM 학습 코드의 뼈대는 반복이다.

```text
for epoch in epochs:
    for batch in dataloader:
        예측 → loss 계산 → 역전파 → 파라미터 업데이트
        if step % 100 == 0:
            로그 출력
        if loss가 충분히 작으면:
            조기 종료
```

조건문과 반복문을 모르면, Transformer 수식을 알아도 **학습 코드를 읽거나 쓸 수 없다**.

이번 강의는 문법 자체보다, 나중에 만날 **훈련 루프의 미니어처**를 손에 익히는 데 초점을 둔다.

### 3. 먼저 알아야 할 개념

#### 3.1 Control Flow

**Control Flow(제어 흐름)**는 코드가 어떤 순서로, 어떤 조건에서, 몇 번 실행되는지를 말한다.

기본은 위에서 아래로 한 줄씩이다.  
조건문·반복문은 그 직선 도로에 **갈림길**과 **원형 교차로**를 추가한다.

#### 3.2 Indentation (들여쓰기)

Python은 **들여쓰기**로 코드 블록을 구분한다. 중괄호 `{}` 대신 공백(보통 4칸)을 쓴다.

```python
if True:
    print("이 줄은 if 블록")
print("이 줄은 if 밖")
```

들여쓰기가 어긋나면 `IndentationError`가 난다. 초반에 가장 흔한 문법 실수 중 하나이다.

### 4. 핵심 개념 설명

#### 4.1 if / elif / else

**if**는 조건이 참일 때만 블록을 실행한다.

```python
loss = 2.5

if loss < 1.0:
    print("충분히 낮다")
elif loss < 2.0:
    print("중간")
else:
    print("아직 높다")
```

출력:

```text
아직 높다
```

- `if`: 첫 조건
- `elif`: 그다음 조건 (여러 개 가능)
- `else`: 앞 조건이 모두 거짓일 때

조건식은 보통 `bool`이 된다. `>`, `==`, `and`, `or`, `not`을 조합한다.

#### 4.2 비교 시 주의

```python
x = 0.1 + 0.2
if x == 0.3:
    print("정확 일치")
else:
    print("미세 오차 가능")
```

float 비교는 `==`보다 허용 오차가 안전할 때가 많다.

```python
eps = 1e-9
if abs(x - 0.3) < eps:
    print("거의 같다")
```

#### 4.3 for 반복

**for**는 시퀀스의 원소를 하나씩 꺼내 반복한다.

```python
tokens = ["오늘", "날씨가", "좋다"]
for t in tokens:
    print(t)
```

문자열도 글자 단위로 순회할 수 있다.

```python
for ch in "GPT":
    print(ch)
```

#### 4.4 range

**range**는 정수 수열을 만든다. `for`와 함께 자주 쓴다.

```python
# 0, 1, 2
for i in range(3):
    print(i)

# 1, 2, 3, 4
for step in range(1, 5):
    print(step)

# 0, 2, 4
for i in range(0, 5, 2):
    print(i)
```

형태:

```text
range(stop)
range(start, stop)
range(start, stop, step)
```

`stop`은 포함되지 않는다. `range(3)` → 0, 1, 2.

학습 스텝을 흉내 내면:

```python
num_steps = 5
for step in range(1, num_steps + 1):
    print(f"step={step}")
```

#### 4.5 while 반복

**while**은 조건이 참인 동안 반복한다.

```python
loss = 3.0
step = 0

while loss > 1.0 and step < 10:
    # 아주 단순한 "학습" 흉내: 매 스텝 loss가 줄어든다고 가정
    loss = loss - 0.4
    step += 1
    print(f"step={step}, loss={loss:.1f}")
```

출력 예:

```text
step=1, loss=2.6
step=2, loss=2.2
step=3, loss=1.8
step=4, loss=1.4
step=5, loss=1.0
```

`while`은 종료 조건을 잘못 쓰면 **무한 루프**가 된다. 반드시 조건을 거짓으로 만드는 갱신이 있는지 확인한다.

#### 4.6 break와 continue

**break**는 반복을 즉시 종료한다.  
**continue**는 이번 회차의 나머지를 건너뛰고 다음 회차로 간다.

```python
for step in range(1, 11):
    if step % 2 == 0:
        continue          # 짝수 스텝은 로그 생략
    if step >= 7:
        break             # 7 이상이면 중단
    print(f"log step={step}")
```

출력:

```text
log step=1
log step=3
log step=5
```

ML 비유:

- `continue`: 잘못된 배치를 건너뛰기
- `break`: early stopping으로 학습 종료

#### 4.7 중첩 루프

루프 안에 루프를 둘 수 있다.

```python
num_epochs = 2
steps_per_epoch = 3

for epoch in range(1, num_epochs + 1):
    for step in range(1, steps_per_epoch + 1):
        print(f"epoch={epoch}, step={step}")
```

실제 학습도 “에폭 루프 × 배치 루프” 구조인 경우가 많다.

### 5. 직관적으로 이해하기

| 구문 | 직관 | LLM 비유 |
|---|---|---|
| if/elif/else | 갈림길 | loss가 크면 로그, 작으면 저장 |
| for | 목록을 순서대로 처리 | 배치를 하나씩 학습 |
| while | 목표에 닿을 때까지 반복 | loss가 기준 이하가 될 때까지 |
| break | 중간에 멈추기 | early stopping |
| continue | 이번 것만 건너뛰기 | 결측 배치 skip |
| range | 횟수 티켓 | step=1…N |

중요한 감각:

> 모델이 똑똑해지는 과정도, 코드 관점에서는 **같은 계산을 수많은 배치에 대해 반복**하는 일이다.

### 6. 작은 숫자 예제 — 가짜 학습 루프

초기 loss가 4.0이고, 매 스텝 0.5씩 감소한다고 가정한다.  
loss가 1.0 이하이거나 step이 20을 넘으면 멈춘다.  
3의 배수 스텝에서만 로그를 남긴다.

손으로 추적:

| step | loss | 로그? | 종료? |
|---:|---:|---|---|
| 1 | 3.5 | X | X |
| 2 | 3.0 | X | X |
| 3 | 2.5 | O | X |
| 6 | 1.0 | O | O (loss≤1) |

코드:

```python
# toy_train_loop.py
# 목적: 조건문·반복문으로 학습 루프를 축소해 본다.

def main() -> None:
    loss = 4.0
    max_steps = 20
    target = 1.0

    for step in range(1, max_steps + 1):
        loss -= 0.5

        if step % 3 != 0:
            continue  # 로그 주기만 흉내

        print(f"step={step}, loss={loss:.1f}")

        if loss <= target:
            print("early stopping")
            break
    else:
        # for가 break 없이 끝난 경우에만 실행
        print("reached max_steps")


if __name__ == "__main__":
    main()
```

`for ... else`는 break 없이 정상 종료될 때 `else`가 실행된다. 알아 두면 디버깅에 도움이 된다.

### 7. 코드로 확장하기 — 토큰 생성 루프 스케치

1강에서 본 next-token 생성도 반복문이다.

```python
# generate_loop.py
# 목적: 생성 = "다음 토큰 선택"의 반복임을 코드로 고정한다.

def pick_next(last: str) -> str:
    table = {
        "오늘은": "날씨가",
        "날씨가": "좋다",
        "좋다": ".",
    }
    return table.get(last, "...")


def generate(prompt_tokens: list[str], max_new: int = 5) -> list[str]:
    tokens = list(prompt_tokens)
    for _ in range(max_new):
        nxt = pick_next(tokens[-1])
        tokens.append(nxt)
        if nxt == ".":
            break  # 문장 끝 토큰이면 중단
    return tokens


if __name__ == "__main__":
    result = generate(["오늘은"], max_new=5)
    print(" ".join(result))
```

출력 예:

```text
오늘은 날씨가 좋다 .
```

실제 GPT 생성은 `pick_next` 자리가 거대한 신경망으로 바뀐다.  
그러나 **바깥 루프의 모양**은 크게 다르지 않다.

### 8. 실제 LLM에서는 어떻게 사용하는가

| 문법 | LLM 코드에서의 전형적 사용 |
|---|---|
| for epoch / for batch | Pretraining, SFT 학습 루프 |
| if step % N == 0 | 일정 간격 로깅, 평가, 체크포인트 |
| if loss.isnan() | 수치 불안정 감지 후 skip/중단 |
| while not done | 대화 에이전트, 도구 호출 루프 |
| break | early stopping, max length 도달 |
| continue | 빈 샘플·손상 샘플 건너뛰기 |

Inference(생성)에서도:

```text
while 아직 끝 토큰이 아니고 길이가 max_len 미만:
    다음 토큰 예측
    토큰 추가
```

조건·반복은 “모델 구조”만큼이나 “학습·생성 운영”의 핵심이다.

### 9. 실습

#### 실습 1 — 등급 나누기

`loss` 값에 따라 메시지를 출력한다.

- `loss < 1`: `good`
- `1 <= loss < 2`: `ok`
- 그 외: `high`

여러 값(0.5, 1.5, 3.0)으로 테스트한다.

#### 실습 2 — 배치 루프

`num_batches = 8`일 때, 4의 배수 배치에서만 `checkpoint`를 출력한다.  
단, 배치 번호가 7 이상이면 전체 루프를 `break`한다.

#### 실습 3 — while로 목표 도달

`accuracy = 0.4`에서 시작해 매 스텝 `0.07`씩 증가시킨다.  
`accuracy >= 0.9` 또는 `step == 20`이 되면 멈추고, 최종 step과 accuracy를 출력한다.

### 10. 자주 하는 실수

1. **들여쓰기를 탭/스페이스로 섞는다**  
   에디터에서 스페이스 4칸으로 통일한다.

2. **`=`와 `==`를 혼동한다**  
   `=`는 대입, `==`는 비교이다. `if loss = 1.0`은 문법 오류다.

3. **while 조건을 갱신하지 않는다**  
   무한 루프의 대표 원인이다. 루프 변수 변화를 눈으로 추적한다.

4. **range 끝값을 포함한다고 착각한다**  
   `range(1, 5)`는 1~4이다. `num_steps`번 돌리려면 `range(num_steps)` 또는 `range(1, num_steps+1)`을 의도적으로 고른다.

5. **break/continue 위치를 잘못 둔다**  
   로그를 찍기 전에 break하면 원인 파악이 어려워진다. 종료 직전 로그를 남기는 습관이 좋다.

### 11. 핵심 정리

- if/elif/else는 조건에 따라 다른 코드를 실행한다
- for는 시퀀스·range를 순회하고, while은 조건이 참인 동안 반복한다
- break는 종료, continue는 이번 회차 건너뛰기이다
- 학습 루프와 생성 루프는 모두 조건·반복의 응용이다
- 들여쓰기가 Python 블록의 경계이다

### 12. 핵심 용어

| 용어 | 의미 |
|---|---|
| Control Flow | 코드 실행 순서·조건을 제어하는 개념 |
| if / elif / else | 조건 분기 문법 |
| for | 시퀀스 순회 반복 |
| while | 조건 기반 반복 |
| range | 정수 수열 생성기 |
| break | 반복 즉시 종료 |
| continue | 현재 회차 나머지 건너뛰기 |
| Indentation | 블록을 구분하는 들여쓰기 |
| Early Stopping | 성능/손실 기준에 도달하면 학습을 일찍 끝내는 전략 |
